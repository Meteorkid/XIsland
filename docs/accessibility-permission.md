# 辅助功能权限说明

本文说明 X Island 为什么需要「辅助功能」权限、如何授权，以及为什么更新后需要重新授权一次。可直接用于官网产品页或应用内帮助。

## 这个权限用来做什么

X Island 的会话卡片提供「继续下一步」按钮：

1. 把指令「继续下一步」写入剪贴板
2. 激活该会话所在的终端窗口
3. 向该窗口发送一次 ⌘V，把指令粘贴进输入框
4. 提示「已粘贴，按回车发送」

第 3 步需要向其他应用发送键盘事件，macOS 只允许获得「辅助功能」权限的应用这样做。除此之外没有其他途径。

## 如何授权

首次点击「继续下一步」且尚未授权时，X Island 会同时做两件事：

- 打开 **系统设置 → 隐私与安全性 → 辅助功能**
- 在 Finder 中选中 `/Applications/X Island.app`

然后把 Finder 里的 **X Island** 拖进辅助功能列表即可（也可以点列表下方的 `+` 手动选择应用）。

授权后回到 X Island，再次点击「继续下一步」即可自动粘贴。

## 为什么每次更新后要重新授权

X Island 目前使用 **adhoc 签名**（没有 Apple 开发者证书）。macOS 的权限系统按「应用身份」记录授权，而 adhoc 签名的身份就是可执行文件的哈希。

更新版本后文件内容变化 → 哈希变化 → 系统认为这是一个新应用 → 旧授权不再匹配，需要重新拖入一次。

这与「应用是否可信」无关，是 macOS 对未签名应用的固定规则。要跨版本保留授权，需要使用 Apple Developer ID 证书签名，这需要付费开发者账号。

## 未授权会影响什么

不会影响其他功能。未授权时：

- 指令仍然会被复制到剪贴板
- 窗口仍会被激活
- 提示变为「已复制；把 /Applications/X Island.app 拖入「辅助功能」列表即可」
- 你手动按 ⌘V、再按回车，效果与自动粘贴完全一致

## 常见问题

**Q：已经勾选了 X Island，为什么还提示未授权？**

A：先确认勾选的是 `/Applications/X Island.app` 这一个副本。如果应用被复制到其他位置（例如 `~/.build` 或下载目录），系统会把它当成另一个应用。另外，更新版本后需要重新拖入一次。

**Q：为什么日历、通讯录权限不需要每次授权？**

A：它们同样受代码签名约束。区别在于这些功能没有随每次版本更新被替换；一旦替换应用文件，同样会失效。

**Q：能不能自动完成授权？**

A：不能。辅助功能是系统级隐私权限，必须由用户在系统设置中手动授予，应用无法代劳。
