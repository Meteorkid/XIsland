# XIsland 安全与跨平台可靠性专项计划

日期：2026-10-18。目标：在现有 Mac / Windows 功能基础上，优先让审批、更新、数据和接入可信，再扩大真实客户端覆盖。用户已授权直接实施和验证，不设置方案审批门槛。

本专项对应[总优化计划](optimization-plan-2026-10-18.md)中的安全恢复与跨平台验收部分；历史分页、导出和性能改进继续由总计划跟踪。以下三个阶段用于本专项的验收，不替代总计划的 A–D 顺序。

## 判断与范围

当前具备完整的会话、待办、交互和接入框架，已有较多隔离测试；Mac 更接近功能完整的测试版，Windows 仍是待实机验收的开发预览。适配数量、配置存在或浏览器测试通过，均不能代表真实 Agent 已完成接入。

本轮审查盘点 750 个仓库文件，对 105 个关键源文件/配置做完整内容审阅，重点覆盖双端 IPC、审批、适配器、安装、更新和凭据边界。两处确认的中危问题已隔离复现：审批摘要可能隐藏实际操作；Mac 按文本相似度自动复用上一条回答。此数字是关键路径覆盖，不是全仓逐行审查，也不是无漏洞证明。

## 方案取舍

采用按边界的小步修复：在消息进入审批状态时保留真实参数；更新器以验证、暂存、备份、替换组成事务；额度按真实单位建模。直接重写双端会话系统会扩大回归面；只增加界面提示则不能修复数据丢失和错误状态，因此暂不采用。Swift 与 TypeScript 保持各自平台实现，通过共用场景与验收条件对齐行为。

## 第二阶段：接入恢复和跨平台一致性

按以下顺序实施，每项独立验证与记录：

1. **Windows CI（工作流已写入）**：Windows runner 执行 TS、Rust 原生管道、桌面编译及 Playwright；已有 Mac Swift CI 保留。YAML 已校验，远端运行待验；写入 YAML 不等于通过。
2. **Codex 配置位置（防误写已完成）**：检测非默认 `CODEX_HOME` 时，当前自动管理明确拒绝，不写默认或自定义文件。默认、空值、显式默认目录保持兼容；相对路径、外部目录及计划后切换已有回归。未来完整支持自定义目录时，再增加路径绑定和符号链接策略；不修改信任记录。
3. **安装锁恢复**：异常退出不能永久阻塞接入。优先有进程归属且不会抢占活跃操作的机制；禁止仅按文件年龄删除锁。验收使用真实子进程强制退出、并发安装、PID 复用/未知归属及旧锁兼容场景，保持配置 revision 和备份保护。
4. **交互生命周期**：请求过期及时反馈；旧工具完成事件不能清除新审批；退出、断线、重放不能隐式批准。双端使用同一组录制/合成场景，核对事件 ID、turn ID 与工具 ID。
5. **协议一致性**：OpenCode 会话删除、Qwen 子会话、Claude 多问题/多选、未知工具结果与终态使用明确的支持/回退合同。未支持的交互回到原客户端，不能制造成功。
6. **资源上限**：Mac socket 读期限/连接数、桥接 stdin 上限、token 数值校验；Windows 历史/队列/已用 transport 集合的数量与总字节上限。用慢连接、大包、长会话压力夹具验证，不对真实服务压测。

## 后续收口，不抢占前三阶段

- SSH 先连通部署、隧道、远端 ABI 与断线恢复的完整路径，再标记已连接；当前 UI 配置/连通测试不能替代实际隧道验收。
- Git checkpoint 在接入生产调用前，明确 stash 对工作树的影响，恢复依据稳定对象 ID，避免只按描述匹配。
- 将设置中的“已安装、已配置、已授权、已收到事件、已验证交互”分开呈现，并同步 README 能力表。
- 仅在测试覆盖到位后抽取重复安装事务和会话状态不变量，不进行跨全仓的大规模重构。
- 实际组件渲染发现：零会话普通展开态仍按 94 点估算面板高度，未计入 Agent Flow 和额度区域，底部可被裁切。该问题已复核到 `IslandSizeCalculator`，交给总计划界面阶段按内容测量解决；不能用本次截图生成成功宣称完整展开视图通过。默认宽度下本地用量会换行，后续优化紧凑文案和完整提示。

## 验证记录与交付规则

- Mac：`X_ISLAND_TEST_MODE=1 swift test`；针对快照测试显式提供隔离输出目录。
- Windows：`npm run check`、`npm test`、`npm run build`、`npm run build:hook`、`npx playwright test`；原生层 `cargo test --locked --no-default-features`，目标环境另做桌面编译与管道测试。
- 升级：命令 stub + 临时 app 目录验证失败恢复，不对实际 `/Applications` 执行测试。
- 依赖：本轮官方 npm audit 返回 0 条已知公告；不代表 Rust 依赖或零日漏洞已验证。当前镜像 audit API 不支持，使用单次命令指定官方 registry，没有更改全局源。
- 保留既有未提交的 Mac 接入界面工作。本计划的修复不能被描述为那些工作已完成发布。
- 复现、修复证据与完整审查结果保存在 Codex Security 的独立审查产物中；原扫描报告保持修复前快照，修复验证单独记录。

2026-10-18 本轮隔离快照：Swift 1229 项、0 失败、8 项可选渲染跳过；另执行审批渲染和临时额度组件渲染 2/2，并人工查看输出。Windows 594 项测试、52 项浏览器交互、check/build/build:hook 全通过；Rust 核心 23 项和 IPC 1 项通过，island-link 17 项通过；CLI 22 项通过。另一聊天仍在同仓库继续修改后续测试，因此这些数字绑定本轮验证快照，不替代下一次提交前检查。
