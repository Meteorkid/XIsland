# Windows XIsland 实施目标与验收计划

基准日期：2026-10-13。状态：执行中。用户已授权实现高度还原当前 macOS 版的 Windows 客户端，并在另一台 Windows 电脑进行最终验收。

## 产品目标

Windows 版保持 XIsland 的顶部灵动岛、视觉语言和主要操作路径，覆盖当前 macOS 版全部有依据的功能。新增的系统适配应改善 Windows 上的焦点、缩放和稳定性。“只能更好”落实为与冻结基准比较的验收目标，不在测量前承诺性能或兼容性优于现版。

现有 macOS 工作树含大量未提交修改，实施以新增 `windows/` 和 `docs/windows/` 为主，不重置、不自动提交、不发布。基准清单见 `baseline-manifest.json`，源码和截图的差异由 `visual-baseline.md` 解释。

## 方案与选择

1. **采用：Tauri 2 + Rust + TypeScript。** Windows 原生层负责窗口、通信、文件与系统集成；纯 TypeScript 核心负责协议校验与可测试会话规则；界面按现有 SwiftUI 视觉规格重建。前端可在 macOS 浏览器检查，原生后端单独编译和测试。
2. Electron：Windows 分发和 JS 生态方便，但常驻 Chromium 的成本不符合本项目优先考虑轻量悬浮工具的方向；参考其审批与窗口设计，不直接沿用运行时。
3. C# / WinUI / SkiaSharp：适合深度原生 Windows 实现，但当前开发主机和已有协议测试复用更适合第一种方案；保留其窗口处理思路作为实现参考。

不复制 GPL/AGPL 项目源码到当前许可下。记录参考来源与设计启发，重新实现平台行为。MIT 代码如确需引入，逐文件登记来源、版本、原始许可；初始实现不引入第三方项目源码或品牌资产。

## 模块与数据流

`原生 Agent hook → xisland-bridge → 按用户隔离的本地管道 → Rust 服务 → DIMessage → 会话核心 → 界面`

审批反向走同一请求连接；请求唯一标识、会话身份和原生请求身份必须一致。过期、断连、重复点击和失效响应不能显示为成功。Windows 默认使用 Named Pipe，本机开发使用隔离 Unix socket。真实客户端原生格式在 adapter 层映射，不因名字相近套用其他客户端协议。

- `windows/src/core/`：DIMessage 校验、会话状态、主子代理、交互请求、累计用量、历史序列化；不依赖 DOM 或操作系统。
- `windows/src/ui/`：收起胶囊、展开列表、内联交互、历史/统计、设置、主题、可访问性和音效展示。
- `windows/src/platform/`：前端与 Tauri 的窄接口；浏览器预览明确标识为样例模式。
- `windows/src-tauri/`：本地传输、窗口定位/焦点、存储、CLI 桥接与系统命令。
- `windows/scripts/`：Windows 构建与验收脚本。测试运行时独立目录、独立管道，避免修改真实 Agent 配置。
- `docs/windows/`：功能矩阵、来源与设计取舍、执行日志、检查与实机证据。

## 验收要求

- **视觉与行为**：以当前代码为准。默认收起宽 261.34、高 38.77；ticker 开启时增加 22；默认展开宽 380。无刘海显示器布局优先，保留贴顶形态。字体使用合法系统字体，允许字形平台差异，布局、信息层级与交互路径须保持一致。
- **交互可靠性**：审批不串会话、不重复提交；原生客户端处理后界面及时消除；问答支持选项、自定义文本与多选；计划支持批准及反馈。任何失败或超时保持可解释状态。
- **会话正确性**：主/子代理终结规则、原生后台任务、重放和乱序去重、观察租约、累计用量分别测试；历史不会因页面刷新丢失或把归档会话复活。
- **平台体验**：鼠标穿透只应用透明区域；悬停不抢焦点，输入框工作时允许焦点；边界屏幕/DPI变化不丢失窗口；减少动态效果与键盘导航可用。
- **真实性**：不把测试样例写入真实历史，不把占位界面当功能完成，不按适配数量宣称兼容。配额区分已用量、余额、限额、未知，不做金额到 token 的臆测换算。
- **性能**：记录空闲与多会话工作负载的 CPU、内存和输入响应；与同等场景的基准比较，当前不填未经测量数字。
- **发行**：构建成功、安装包生成、实机通过是三种不同状态。签名和对外发布需另外处理，不自动推送、提交或发布。

## 验证命令与证据

计划在 `windows/` 提供 `npm run check`、`npm test`、`npm run build`、`npm run tauri -- build`。每次交付记录实际执行的命令、结果、源码版本与产物路径；未安装的工具或不可用的系统不能用推断补足。

最终 Windows 验收在用户另一台电脑进行。届时提供可直接运行的检查脚本与问题收集输出；当前主机如使用虚拟机，需明确用户授权和资源影响后再启动。

## 任务约束

- 遵守现有 macOS 适配矩阵的证据边界，不借本次移植宣称原有 30 个目标已全部完成。
- 凭据不进入日志、配置样例或 Git。联网服务、SSH 与更新均由用户设置触发；本地预览不运行实际 Agent。
- 仓库目前没有根级项目 AGENTS.md。本次给新增 Windows 子项目建立独立说明，避免扩大现有 Mac 项目的规范范围。
- 不自动执行 Git add/commit；里程碑完成后向用户报告可提交范围。
