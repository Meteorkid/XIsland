# Windows XNook ↔ XIsland 联动协议 v1

实现分别保存在两个仓库 `windows/crates/island-link/`，内容一致，构建时不引用另一个仓库。Rust 最低 1.89（使用标准库跨进程文件锁）。需要 XNook Windows 0.1.0 与 XIsland Windows 0.1.4 或后续兼容版本；旧 XIsland 0.1.3 不支持此协议。

## 使用

1. 安装并启动两个新版客户端各一次。每个客户端只登记自己的实际可执行路径。便携版移动位置后需再次运行该客户端登记。
2. XNook 的 XIsland 按钮与 XIsland 展开标题中的 `XNook →` 按钮双向切换；标题或折叠浮岛区域也支持横向滚动。
3. 未运行但已登记的对方由固定可执行路径启动，不传入外部命令、URL、参数。
4. 托盘“显示”和重复启动应用共用显示权协调。退出当前显示者后，另一个仍运行的新版客户端接位。

不能在未启动登记过的安装包、旧客户端、全屏阻止显示、启动失败或已卸载情况下假装成功。失败文案留在当前应用。首次登记不是安装器扫描：未登记时状态会提示先启动对方一次。

## 目录和信任边界

生产目录固定为当前用户 `%LOCALAPPDATA%\Islands\link-v1`，不接受前端提供的路径。Windows 采用当前用户 LocalAppData 权限继承；Unix 的独立测试目录限制为 0700。不会使用网络监听端口、公共临时目录、共享全局服务或管理员权限。

身份只有 `xnook`、`xisland`，注册时验证当前进程可执行名分别为 `xnook.exe`、`xisland.exe`。双方的可执行路径由各自运行进程登记，调用方不能上传执行路径。状态含协议版本；不兼容或损坏时失败并保留原文件。注册信息用于当前用户应用协作，不把同一用户权限下的恶意程序视为额外的安全边界。

## 锁、事务与窗口门禁

- `xnook.running` / `xisland.running`：实例存活锁，持有至进程退出，进程崩溃由内核释放。注册文件可以保留用于下次启动。
- `<identity>.<instance UUID>.lease`：每次启动独立的实例租约锁，ready 绑定这个租约。目标退出并立即重启也不能继承旧实例的显示确认；新实例启动会撤销本身份遗留 owner / ready。
- `coordinator.lock`：同一用户的全局协调锁。同启只有一个进程获得空显示位；同时切换按锁顺序处理，活跃请求拒绝插队。
- `state.json`：协议、owner、唯一 UUID 请求、源和目标、截止时间、ready 和最终 ACK。每次更新通过同目录临时文件替换；无效状态不会静默清空。
- 目标在锁内调度主线程的原生 show，验证窗口实际可见后写 ready。若因全屏等原因未显示，不确认。
- 源收到 ready 后才隐藏原窗口；隐藏成功后才提交新 owner 和最终 ACK。源隐藏失败时恢复原窗口并报告失败，目标放弃临时显示。
- 每个请求在 show/hide 回调返回后再次核对截止时间；迟到显示撤回，迟到隐藏恢复。锁等待和操作耗时包含在请求期限内。
- 切换请求只在最终 ACK 匹配请求 ID 和目标身份、owner 仍一致时 resolve。临时读写异常不会让请求提前失败后继续迟到提交，而是等待其截止时间。
- 窗口控制器所有 resize、展开、全屏恢复、拖动、Agent 状态导致的刷新都必须读取 `owns_display()` 内存门禁。已让位客户端仍可更新内容，但不能重新显示。
- 协调器在后台线程持锁执行回调；Tauri 宿主把原生窗口动作调度到主线程并等待其完成。主线程不能调用阻塞的 switch/request_show；命令与托盘入口通过 `spawn_blocking` 执行，避免自己等待自己。

从目标显示到源隐藏存在一个很短的事务交接间隔，这是“目标成功后才隐藏源”的必要顺序；稳定状态只能有一个 owner。它不是跨进程原子绘制或 Windows 实机帧级无闪烁承诺。

## 对外 API

- `island_peer_status() -> {installed,running,compatible,detail}`。
- `switch_island() -> void`：最终确认后 resolve；失败 reject。
- `island-link-error` 事件：后台协调或原生窗口错误字符串。

这些 API 不接受应用名称、可执行路径或任意命令。联动不接触 Agent 审批、会话协议、笔记、媒体和日历数据。

## 验证

`cargo test --manifest-path windows/crates/island-link/Cargo.toml` 启动两个独立子进程并使用隔离目录，覆盖来回切换、原生显示入口语义、并发启动/切换、源退出、启动已停止对方、目标缺失/show失败、迟到show、源hide失败、ready及最终ACK写入失败、目录隔离、原 owner 重启、目标 ready 后退出和立即重启，以及源隐藏后目标实例租约读取失败的恢复。测试的原生窗口动作由可控回调代替，不等同真实 Windows 窗口验收。

Windows 实机仍须验证：安装两包并首次登记，双向按钮/手势切换，退出后唤醒，托盘/重复启动，开启全屏自动隐藏后切换再退出全屏，多屏与缩放切换，目标未安装/旧版/窗口启动失败。查看屏幕与实际窗口可见状态，不能仅凭 ACK 文件视为通过。
