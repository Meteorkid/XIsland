# X Island v2.0.1

本次更新简化了 AI 软件的首次接入：自动准备支持的配置，并在需要用户确认时显示清晰的授权引导。

## 新增

- 增加了统一的“软件接入与授权”窗口，可从菜单栏或设置打开。
- 增加了已安装软件检测，只为已启用且支持自动配置的来源准备配置。
- 增加了 Codex 实际信任状态检查，并引导用户在 Codex 中审阅和信任 X Island hooks。
- 增加了 WorkBuddy 插件和 Kiro V3 配置文件的自动准备，可直接从界面在 Finder 中取用。

## 改进与修复

- 记住了同一配置的提醒与接通状态，避免每次启动重复设置。
- 区分了“待配置”“待授权”“等待活动”和“已接入”，不再仅凭配置文件存在显示连接成功。
- 修复了检查过程中关闭窗口后再次弹出、开关变化后未及时刷新，以及短任务活动在检查期间漏记的问题。
- 支持了配置被客户端重写后的自动修复，并保留用户修改过的接入文件。

## 使用与范围

信任操作仍在原客户端由用户确认；X Island 不会替用户授予信任。需要外部 Agent、服务地址或启动参数的来源仍需完成一次性设置。Kiro 文件面向 2.31.0 V3 模板，生成成功不代表已检测本机版本或已被客户端加载。

“已接入”表示当前配置收到有效活动，不代表所有功能、客户端版本和服务商均已验收。详细范围见[接入说明](https://github.com/Meteorkid/XIsland/blob/v2.0.1/docs/compatibility/README.md)，本次测试与产物见[公开验证摘要](https://github.com/Meteorkid/XIsland/blob/v2.0.1/docs/compatibility/release-verification-2.0.1.json)。

本次安装包面向 Apple Silicon，要求 macOS 14 或更高版本；不包含新的 Windows 发布。配套 VS Code 扩展继续使用独立的 1.0.0 版本。

## 验证

最终构建通过了 1132 项 Swift 测试（0 失败、0 跳过）、122 个编译桥接场景、WorkBuddy 11 类导出事件，以及隔离 X Island 的 Codex 生命周期 21 条合成消息和 23 个检查点。10 张接入界面快照已生成并检查；以上不代表真实客户端已授予信任或完成全部验收。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
