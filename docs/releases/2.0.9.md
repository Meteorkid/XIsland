# X Island v2.0.9 — Codex 聊天标题修复

本次修复了 Codex 回复授权或确认问题后，灵动岛把内部回复标签显示成聊天标题的问题，让任务卡片和历史列表重新显示可读的用户答案。

## 聊天标题恢复可读

- 修复了确认弹窗回复被当成整段内部消息保存的问题，现在会提取实际答案，例如“设置已打开，可以继续”。
- 修复了任务卡片、收起态图标提示及历史列表中出现内部回复标签的问题，旧记录也会按同一规则显示可读标题。
- 多项回答按原顺序保留，回复后附加的正文继续保留，长标题沿用现有截断规则。
- 空回复、截断或结构损坏的内部消息不再覆盖已有有效标题，新会话缺少有效标题时使用项目名。

## 兼容旧记录与旧桥接

- 新消息在进入会话、聊天历史及保存路径前完成解析，避免内部问题编号等元数据继续成为任务提示。
- 兼容尚未更新的桥接程序发送的原始回复包装，应用端也会完成相同处理。
- 已有历史记录仅调整标题显示，原始提示和聊天内容继续保留，没有数据库结构变更，也不批量重写历史。
- 同一聊天的任务编号、配色和吉祥物归属保持不变，完成未查看与会话生命周期规则保持原样。

## 保留正常文本和客户端行为

- 仅识别 Codex 的精确顶层问答回复包装，普通文字、XML、代码围栏和行内标签说明继续按原文处理。
- 其他客户端的消息不套用 Codex 专用解析规则。
- 对嵌套包装采用有界处理，避免桥接与应用重复解析时反复改变内容；纯内部起始标签或损坏包装不会成为标题。
- 本次没有改变现有客户端的 hook 配置格式或原生授权流程，也没有新增客户端接入能力。

## 验证结果

- 新增 **26 项回归测试**，覆盖可读答案、多项回答、损坏输入、普通文本保留、旧桥接、旧历史显示和重复解析。
- macOS 全量 **1,570 项：1,553 通过、17 项按需测试跳过、0 失败**，其中新增 14 项全部执行并通过。
- Windows 的类型检查、**615 项测试**和前端构建通过，其中新增 12 项回归全部通过。
- 编译后的桥接与隔离 App 完成 **23 个合成原生事件、25 个检查点**，核对用户答案保存、损坏回复保护、数据库、用户历史及重启恢复。
- 对正式 2.0.9 打包结果另行核对版本、arm64 架构、签名自洽性与校验和，发行验证摘要见 [2.0.9 验证记录](https://github.com/Meteorkid/XIsland/blob/v2.0.9/docs/compatibility/release-verification-2.0.9.json)。

上述隔离链路是可重复的协议测试；真实厂商客户端全部状态闭环、VoiceOver 朗读、持续原生帧率和外接多屏仍需单独验收，Windows 检查也不代表 Windows 实机验收。

## 升级与下载

本版提供 **Apple Silicon（arm64）macOS 安装包，最低 macOS 14**。从 2.0.8 升级不新增历史库迁移，已有任务和显示偏好继续保留；无需清空历史来修复标题。

VS Code 配套扩展维持 **1.0.1**，已有该版本的用户不需要为本次标题修复重装扩展。Windows 同步了源码修复，本次没有新 Windows 安装包。

当前 macOS 包仍为 ad-hoc 签名，尚未提供 Developer ID 签名或公证。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
