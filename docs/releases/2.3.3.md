# X Island v2.3.3 — Swift 6.1 构建兼容修复

日期：2026-11-28

2.3.3 是 2.3.2 的兼容性补丁。它修复了两处 Swift 6.1 干净构建失败：SwiftUI `@State` 名称遮蔽，以及 `QuotaTracker` 的 `isolated deinit` 需要实验开关。正常轮询、额度读取和界面行为不变。

## English summary

X Island 2.3.3 fixes two Swift 6.1 source-build incompatibilities found after 2.3.2: a private enum named `State` shadowing SwiftUI's `@State` property wrapper, and an `isolated deinit` that requires an experimental compiler flag on Xcode 16.4. The release is rebuilt from an empty scratch directory and passes the full CI suite on Swift 6.1.2. There are no new AI client integrations.

## Integration changes

None. The integration matrix remains **35 source entries: 30 active and 5 retired-with-history**. No integration is added, removed, or re-classified; contract-test results are not merged with real-client verification.

## 一、为什么需要 2.3.3

2.3.2 发布后，GitHub Actions 在 `macos-15-arm64` + Xcode 16.4 / Swift 6.1.2 上做干净构建，暴露了两处只在旧工具链出现的编译问题：

1. `PermissionsSection` 这个 SwiftUI `View` 自己声明了 `private enum State`，在 Swift 6.1 的名称解析中遮蔽 SwiftUI 的 `@State` 属性包装器。
2. `QuotaTracker` 使用 `isolated deinit`；Swift 6.1 要求 `-enable-experimental-feature IsolatedDeinit` 才能启用该语法。

本地 Swift 6.4.2 的增量构建没有暴露这两个差异，因此 2.3.2 的 DMG 能生成并运行，但源码在 Xcode 16.4 上无法干净编译。2.3.3 同时修复两处问题，并使用空 scratch path 重新完整构建、重新出包，不沿用 2.3.2 的缓存对象。

## 二、改动

- `Sources/DynamicIsland/Views/PermissionsSection.swift`：`private enum State` 改名为 `private enum PermissionState`，`row`、`label(for:)`、`color(for:)` 的签名同步更新；`@State` 属性声明不变。
- `Sources/DynamicIsland/Managers/QuotaTracker.swift`：移除 `isolated deinit`，改为普通 `deinit`，访问已标记 `nonisolated(unsafe)` 的 `timer` 并在销毁时 `invalidate()`；不再依赖 Swift 6.1 的实验编译开关。
- `VERSION`、`Casks/x-island.rb`、`CHANGELOG.md` 和本发行说明更新为 2.3.3。
- 2.3.2 的运行时安全修复、统一质量门禁和发布检查全部保留；详见 [2.3.2 更新说明](2.3.2.md)。
- 没有新增、删除或变更任何 AI 客户端接入。

## 四、升级建议

- 2.3.2 的二进制可以运行，但其源码在 Swift 6.1 上无法干净构建；建议统一升级到 2.3.3。
- 2.3.1 用户升级后仍会保留历史库、审批队列和审计格式。
- 该包继续为 **ad-hoc 签名**。现有更新器会按 fail-closed 规则拒绝 ad-hoc 更新包，不提供自动更新；请手动下载 DMG 覆盖 `/Applications/X Island.app`。
- 覆盖安装后仍需重新授予辅助功能权限；未授权时「继续下一步」仍复制指令到剪贴板，手动 ⌘V 后回车即可。

## 原有使用规则

安装包继续提供免费下载，首次启用联网后开始完整的 **14 天试用**。用户可以选择一个月、一年或永久授权，每份产品授权最多同时使用 **3 台设备**，支持解绑换机。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.

## 辅助功能权限

「继续下一步」需要辅助功能权限才能自动粘贴。应用内 **设置 → 权限** 集中展示状态并提供授权入口；更新版本后需重新拖入一次（ad-hoc 签名的固有限制，应用会自动清理旧条目）。未授权时指令仍复制到剪贴板，手动 ⌘V 后回车即可发送。
