# X Island v2.0.17 — 审批上下文地图

日期：2026-11-05

本版把审批从“只看当前请求”扩展为一次可以快速完成的上下文确认：先看任务、计划和文件变化，再看原因与影响范围，最后批准、拒绝或带着批注回到对应会话。

## 审批上下文地图

- 审批卡片新增四层节点地图：任务、计划、文件变更、待审批。
- 默认只展开「待审批」，任务、计划和变更各显示一行摘要；需要时再单独展开，避免面板一次拉得过长。
- 计划组显示计划标题层级和条数；变更组显示文件数，并支持按新建、修改、删除筛选。
- 新建使用绿色，修改使用橙色，删除使用红色；摘要中的彩色胶囊可以直接打开对应筛选结果。
- 「原因/范围」会从权限描述或待审计划中提取一段可读说明，长文本会截断。

## 节点批注与回跳

- 任务、计划条目和文件条目提供批注入口。
- 可以生成两类预填消息：向 Agent 提问，或要求 Agent 调整该节点。
- 消息包含被引用的分组和节点标题，复制后使用现有会话跳转能力回到对应聊天或终端。
- 无法取得稳定聊天或终端定位时，界面会提示原因，不会把应用窗口跳转冒充精确会话跳转。

## 较上一轮

- 每轮任务完成时保存上下文地图快照，按会话保留最近 20 轮；全局最多保留 300 个会话。
- 展开「较上一轮」可查看新增文件、移除文件、文件类型变化和计划标题变化。
- 差异默认只显示一行摘要，逐条明细按需展开，并限制展示数量。

## 开关与边界

- 上下文地图默认开启，可在「设置 → 通用 → 行为 → 上下文地图」或岛体右键菜单关闭。
- 地图完全由现有会话数据派生，不新增 AI 调用，也不改变 Agent 审批协议。
- 文件操作解析是保守启发式：无法确认路径或操作类型时不显示猜测结果。
- 快照写入失败不会阻塞审批；合成会话、过期事件或缺少真实客户端定位仍会显示相应失败原因。

## 验证

- Swift 全量回归：X Island 2013 项（21 项条件跳过）、授权核心 31 项（1 项条件跳过），均 0 失败；隔离集成测试 126 项通过。
- 本地候选版实测通过：默认仅展开待审批、计划组独立展开、提问/命令批注复制、会话跳转入口和「较上一轮」明细。
- 发行包完成只读挂载、arm64 架构、2.0.17 版本、正式授权公钥/API、签名完整性和挂载内容逐文件一致性核对。应用仍为 ad-hoc 签名、未公证。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
