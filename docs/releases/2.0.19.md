# X Island v2.0.19 — 会话卡片精简、自动展开与授权显示修复

日期：2026-11-17

本版在 2.0.18 的审批上下文地图之上，收敛了日常交互：会话卡片可以只保留 AI 摘要；任务完成与审批可以自动展开面板；永久授权不再显示会被误读为到期日的离线凭证时间。

## 会话卡片「仅摘要」

- 偏好设置 → 显示 → 新增「会话卡片只显示摘要」。
- 开启后隐藏提示词、回复流、当前工具与工具调用列表，只保留标题栏和结束后的 AI 摘要。
- 没有摘要的会话自动回退完整内容，不会只剩一个空标题。

## 任务提醒与自动展开

- 任务完成时自动展开面板，默认开启。
- 审批、问答、计划审核时自动展开，默认开启。
- 两项可分别关闭：右键点击岛 → 任务提醒。
- 同一批到达的提醒在 80 ms 内合并，只展开一次；多个完成取最近到达者，审批优先于完成。
- 多个会话同时请求审批时，展开一次即可看到全部审批卡片，分别处理。

## 跨桌面提醒

- 新增「在所有桌面与全屏应用上强制显示」，默认关闭。
- 开启后，提醒会在当前任意 Space 或全屏应用上显示，不再受桌面切换影响。

## 修复

- 永久授权不再显示「可离线使用至」的具体日期。该日期是离线凭证的刷新周期，不是授权期限；现在显示为「永久有效 · 无需续期（联网时自动刷新离线凭证）」。
- 一个月、一年与试用授权仍显示使用期限与离线期限，语义不变。

## 原有使用规则

安装包继续提供免费下载，首次启用联网后开始完整的 **14 天试用**。用户可以选择一个月、一年或永久授权，每份产品授权最多同时使用 **3 台设备**，支持解绑换机。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
