# X Island v2.0.11 — 简化吉祥物数字显示

本版精简了吉祥物周围的数字：移除了图标右下角的任务编号，以及折叠栏图标组旁的 `+N` 溢出数量，让小尺寸吉祥物的造型、表情和状态更容易辨认。

## 吉祥物显示

- 移除了共享吉祥物组件右下角的数字编号，折叠栏、任务列表、详情及其他使用该组件的位置同步生效。
- 移除了无刘海遮挡布局中图标组旁的 `+N`，超出折叠显示数量的任务仍可在展开列表中查看。
- 保留了各客户端独立的吉祥物造型，同一聊天／任务继续使用固定配色。
- 保留了表情和右上角的状态角标，包括等待授权、等待回答、计划审查、错误及完成未查看等状态。

## 图例与任务识别

- 更新了中文、英文、韩文、日文和法文图例，以“造型认软件、配色区分聊天、表情和角标认状态”说明现有显示方式。
- 更新了更多任务的查找说明，可展开灵动岛查看完整列表，再根据聊天标题和任务内容定位。
- 保留了辅助功能标签和悬停说明中的任务身份、状态与标题，数字隐藏只作用于可见角标。

## 原有设置与数据

“最近任务数量”仍控制折叠栏显示的任务图标数量，待处理交互的优先级和最近活动排序继续沿用；活跃／总会话计数、完整展开列表、历史记录及完成结果的查看确认行为保持原有规则。

从 2.0.10 升级无需重置偏好、重新分配任务身份或迁移数据库，已有聊天的配色和记录可以继续使用。

## 验证结果

- 本地定向 XCTest **22 项全部通过，0 失败、0 跳过**，覆盖折叠任务选择、固定身份与配色、状态语义及原生静态渲染。
- 渲染检查覆盖浅色／深色吉祥物、同一客户端的多个聊天、完成任务卡片、设置图例，以及折叠数量 1／3／5、刘海和无刘海布局。
- 本批 4 个改动文件与上述 22 项测试时的快照哈希一致，随后完成了 macOS Release 构建和安装包验证。

原生渲染检查验证的是静态画面；正式安装后的运行检查和发行提交的 macOS／Windows CI 结果分别记录，不将静态渲染等同于全部运行场景验收。

## 升级与下载

本版提供 **Apple Silicon（arm64）macOS 安装包，最低 macOS 14**，VS Code 配套扩展维持 **1.0.1**，复用上一版本公开发行的相同扩展包。

本批仅调整 macOS 界面和图例，未修改 Windows 源码，也没有新增 Windows 安装包；当前 macOS 包仍为 ad-hoc 签名，尚未提供 Developer ID 签名或公证。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
