# X Island v2.0.24 — 独立权限页与拖拽授权浮窗

日期：2026-11-18

## 独立「权限」页

设置顶部标签栏新增「权限」，位于「通用」之后：

- **辅助功能**：实时状态（已允许 / 未允许）、「打开并浮起图标」、「显示 App」
- **自动化**：标记「按需」，首次跳转终端标签页时由系统询问
- **通知**：显示授权状态
- 底部「刷新状态」，以及授权后需重启应用的提示

「通用」页的隐私区域改为一条提示卡片，点「前往」直接切到权限页。权限页在授权失效时仍可访问，避免被其他页面挡住。

## 授权浮窗

点击「打开并浮起图标」后：

1. 打开系统设置的辅助功能页
2. 轮询等待系统设置窗口出现（最多 6 次）
3. 在其**左侧、顶部对齐**浮起一个拖拽板：虚线框图标、提示「拖到右侧『辅助功能』列表」、关闭按钮
4. 把图标拖进列表即完成授权

细节处理：

- 非激活面板接受首次点击，不需要先点一次激活
- 位移超过 3pt 才启动拖拽，避免误触
- 拖到空白处取消时浮窗保留，只有真正落入列表才收起
- 面板可整体拖动，遮挡时可挪开
- 找不到系统设置窗口时退到屏幕右上角

「继续下一步」未授权时也会自动触发同一浮窗，不需要先去设置页找。

## 窗口布局

- 默认尺寸从 760×520 调整为 **1000×700**，最小 900×560
- 标签栏由固定 72pt 改为均分宽度，文字单行并允许 0.8 倍缩放
- 原因：11 个标签按 72pt 排开需要 824pt，旧窗口宽度不足，两端被裁切

## 原有使用规则

安装包继续提供免费下载，首次启用联网后开始完整的 **14 天试用**。用户可以选择一个月、一年或永久授权，每份产品授权最多同时使用 **3 台设备**，支持解绑换机。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.

## 辅助功能权限

「继续下一步」需要辅助功能权限才能自动粘贴。应用内 **设置 → 权限** 集中展示状态并提供授权入口；更新版本后需重新拖入一次（adhoc 签名的固有限制）。未授权时指令仍会复制到剪贴板，手动 ⌘V 后回车即可发送。
