## 更新内容

- 补齐了计划全文阅读和多行反馈，权限请求可展开完整说明、路径及文件改动。
- 修复了同类 Agent 请求错配、迟到批准和问题选项变化后复用旧答案的问题。
- 增加了审批发送超时与失败反馈，并修复了多项审批结束后的 xnook 显示恢复。
- 修复了历史追加保存遗漏、工具结果未更新，以及后续回答覆盖上一轮回答的问题。
- 增加了历史格式升级前的一致性备份，保存失败的会话可保留并重试。
- 统一了系统与应用的减少动态效果设置，减少了短文本与零速度跑马灯的无效刷新。
- 完善了内联待办去重、活跃/总计轮换、本地化和测试环境隔离。

- 本安装包适用于 Apple Silicon，最低 macOS 14；首次历史格式升级前会在数据库同级 `HistoryBackups` 目录创建包含已提交 WAL 的恢复点，原恢复点不会被覆盖。
- [历史备份与恢复说明](https://github.com/Meteorkid/XIsland/blob/v1.13.1/docs/history-recovery.md)。

- 后台周期快照、自动重启恢复、历史搜索分页和长期性能基线仍属于后续工作，本次未声称达到完整优化PRD的所有目标。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
