# X Island v2.0.5 — 最近任务数量可调

本次增加了收起态的任务数量设置，让灵动岛可以少显示几个吉祥物，同时保留完整任务列表和总数。

## 可以选择显示最近几个任务

- 在“设置 → 显示 → 收起态模块”新增了“最近任务数量”，可选 **1、2、3、4、5**，默认 **3**。
- 普通布局最多横排所选数量的图标，超出部分以“+N”汇总，例如 8 个任务、显示 3 个时，会显示 3 个图标和“+5”。
- 刘海遮挡布局只在所选数量的任务候选中轮换，减少动态效果时显示首个候选。
- 等待授权、回答或计划审核的实际请求优先展示，其余按最近活动排序，因此刚恢复活动的旧任务也能重新出现。
- 相同活动时间使用稳定顺序，减少图标在刷新时不必要的换位。

## 数量设置会自动保存

- 调节数量后立即生效，重新打开设置仍保留上次选择。
- 关闭“显示 Agent 图标”时，数量选项会禁用但不被清空，重新开启后继续使用原值。
- 异常或越界偏好会限制在 1–5 范围内。
- 展开列表、搜索筛选、活跃数、总数、待处理请求及历史数据继续保持完整，数量限制只作用于收起态图标。
- 补齐了中文、英文、韩文、日文和法文标题及说明。

## 如何使用

打开 X Island 设置，进入“显示”，向下找到“收起态模块”，将“最近任务数量”设为喜欢的数量。如果此项不可选，请先开启上方的“显示 Agent 图标”。点击灵动岛展开后仍可查看全部任务。

## 验证与发行范围

本次验证包括最终发行源码的 Swift 回归、最近任务选择、两种收起布局的隔离渲染，以及原生分段控件的选择、保存、重新打开和禁用行为。最终安装包另行核对版本、架构、完整签名与校验和。具体结果见 [2.0.5 发行验证摘要](https://github.com/Meteorkid/XIsland/blob/v2.0.5/docs/compatibility/release-verification-2.0.5.json)。

最终发行源码执行了 **1456 项 Swift 测试，1442 项通过、14 项按条件跳过、0 失败**；打包后二进制通过了 127 个桥接场景、11 种 WorkBuddy 事件和隔离 Codex 生命周期检查。这些接入检查使用受控测试数据，不代表所有客户端的实机验收。

本版基于 2.0.4，仅纳入最近任务显示功能；独立开发中的 socket 认证改造、动画及触感改动不属于本版。现有客户端接入和双岛切换行为保持原有实现。

安装包面向 Apple Silicon（arm64），最低 macOS 14；Windows 本次没有新安装包，VS Code 扩展保持 1.0.0。安装包仍使用 ad-hoc 签名，尚无 Apple Developer ID 签名或公证。VoiceOver 实际朗读、持续 FPS、外接多屏和全部 AI 客户端闭环不在本轮完成声明中。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
