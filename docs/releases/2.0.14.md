# X Island v2.0.14 — 授权状态与激活码体验修复

日期：2026-10-27

本版修复了试用或授权到期、解绑、网络请求迟到及本机凭证存储异常时的边界行为，并统一了激活码和期限名称。已有历史与设置保留，升级无需重新购买。

## 授权到期与恢复

- 阻止了授权锁定前已入队、但尚未处理的审批、问题和计划请求在锁定后重新出现或被自动答复。
- 保留了已接受的历史写入，恢复授权后可以继续接收新的交互请求。
- 取消了停止授权检查时仍在进行的激活、试用和解绑请求，迟到结果不会重新更新界面或启动截止计时器。
- 区分了暂时网络故障与服务器明确撤销：暂时故障仍允许使用未过期的离线凭证，明确撤销后停止放行。

## 解绑与凭证存储

- 修复了服务器明确返回授权失效后，解绑流程仍保留旧可用状态的问题。
- 修复了服务器已完成解绑、但本机保存失败时未立即锁定的问题。
- 支持了临时存储异常恢复后的安全重试，保留了不可解码的旧记录，不会用空记录覆盖它。
- 保留了已观察到的撤销结果，存储恢复后不会重新使用此前的有效凭证。

## 激活界面

- 将期限统一为 **一个月 / 一年 / 永久**，英文统一为 **1 month / 1 year / Lifetime**。
- 将旧版离线码的提示统一为“激活码”，并明确引导联系管理员迁移。
- 修复了成功重新核验后仍显示旧网络错误、或旧错误覆盖新激活诊断的问题。
- 隐藏了试用期间的解绑入口；已激活用户仍可在软件或网站账户中解绑换机。

## 原有使用规则

安装包继续提供免费下载，首次启用联网后开始完整的 **14 天试用**。用户可以选择一个月、一年或永久使用授权，每份产品授权最多同时使用 **3 台设备**，支持解绑换机。

已核验设备最长可离线使用 **7 天**，且不会超过试用或授权的实际到期时间。永久授权无需续费，但仍需要定期联网核验设备状态。

既有有效购买按原权益保留。需要领取激活码时，请使用原购买邮箱登录 [Meteor Store 账户](https://www.imagentx.top/zh/account#software-licenses)。本版没有修改 Windows 客户端或发布新的 Windows 安装包。

## 验证范围

修复后完整回归为 **1866 项：1848 通过、18 条件跳过、0 失败**。覆盖了排队交互、实际截止计时器、模拟唤醒、网络失败与撤销、停止后的迟到响应、存储故障恢复、跨语言签名，以及中英文试用、激活和到期界面。

文案统一后另完成了 **42 项定向测试，全部通过**。真实长期睡眠唤醒和外部客户端在到期瞬间的交互体验仍需实机观察，自动化回归不替代这些验收。

## macOS 安装提示

提供 **Apple Silicon（arm64）macOS 安装包，最低 macOS 14**。安装包仍采用 **ad-hoc 签名**，尚未提供 Developer ID 签名或 Apple 公证。

若提示“无法验证开发者”或“Apple 无法检查其是否包含恶意软件”，请先确认文件来自官方渠道，再通过“系统设置 → 隐私与安全性 → 仍要打开”操作。若提示“将损坏你的电脑”或“已损坏”，请停止使用并联系店主核对，详见 [官网帮助中心](https://www.imagentx.top/zh/docs/macos-cannot-open-app)。

包内版本、正式公钥、正式网站地址、签名完整性、源码及下载校验记录见 [2.0.14 发行验证](https://github.com/Meteorkid/XIsland/blob/v2.0.14/docs/compatibility/release-verification-2.0.14.json)。
