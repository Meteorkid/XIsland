# X Island v2.0.14 — WorkBuddy 完成提醒与自动切回修复

日期：2026-10-27

本版修复了 WorkBuddy 已经完成任务，X Island 却仍把它显示为空闲、没有提醒用户查看结果的问题。开启“任务提醒”后，WorkBuddy 主任务成功完成会自动显示 X Island；当前显示 X Nook 时，也会切回 X Island。

## 完成提醒恢复正常

- 修复了 WorkBuddy 最终完成状态的识别，成功任务会记录完成时间并显示“已完成·未查看”。
- 接通了已有任务提醒流程，完成后会显示 X Island，并按现有动画设置触发吉祥物提醒。
- 保留了实际回复内容，完成状态文案不会覆盖助手正文，也不会多插入一条相同回复。
- 保留了查看确认规则，打开任务详情、成功主动跳转或在历史页标为已查看后，结果会解除未查看标记。

## 同一聊天可以持续提醒

- 修复了同一 WorkBuddy 聊天继续提问后的提醒衔接，新一轮开始后恢复活动，下一轮完成时会再次提示查看。
- 复用了已有完成事件去重，同一完成状态内重复收到结束通知不会再次抢占岛体显示。
- 保留了已查看结果的确认状态，重复结束通知不会把它重新变为未查看。
- 保留了提醒开关的作用，关闭提醒时仍保存完成结果和待查看状态，但不会因此自动切回。

## 正确区分结束原因

- 保留了普通 Stop 的“完成未确认”状态，客户端仍可能继续处理时不会提前宣布成功。
- 保留了取消和中断的空闲状态、失败的错误状态，未知结束原因不会被猜测为成功。
- 保留了子代理结束和会话结束通知的独立处理，不能仅凭子任务通知关闭父任务。
- 保持了 WorkBuddy 插件的观察方式，不新增审批或问答决定，也不代替用户授予原生信任。

## 升级与使用

请正常退出旧版 X Island 后替换应用，再重新打开。已接入并启用 WorkBuddy 观察插件的用户，使用稳定桥接路径时无需重新配置；若曾自行移动插件或桥接程序，请核对原命令指向仍有效的路径。

在 X Island“设置 → 通用”中开启“任务提醒”，即可使用自动切回；已有开启状态会保留。历史记录、已查看标记和自动收起设置继续沿用，无需清空数据。

本版沿用 2.0.13 的试用与激活规则、正式授权服务和公钥，不重置试用、不新增授权套餐，也不要求重新购买。macOS 若要求确认读取原有钥匙串授权记录，请由本人在系统弹窗中完成。

## 测试与验收范围

- 全量自动测试共 1850 项，其中 XIsland 1833 项、共享授权核心 17 项，合计 21 项按环境条件跳过、0 失败。
- 校验了 11 类插件导出命令、隔离 socket、无效载荷处理和中性 stdout，未将合成事件当作真实客户端验收。
- 覆盖了默认提醒队列、重复结束、已查看后重复、新一轮继续、关闭提醒、后台保存、磁盘重开和归档后的迟到结束。
- 在 WorkBuddy 5.9.2 中完成了两轮真实无文件操作任务，均从 X Nook 自动切回 X Island，并验证第一轮查看确认和第二轮重新提醒。

本次通过范围是正常主任务完成和同一聊天续问；真实压缩恢复、并发迟到乱序、嵌套代理完整生命周期和物理动画帧率仍需单独验收。专项记录见 [WorkBuddy 完成提醒验证](https://github.com/Meteorkid/XIsland/blob/v2.0.14/docs/verification/2026-10-27-workbuddy-completion.md)，发行包证据见 [2.0.14 发行验证](https://github.com/Meteorkid/XIsland/blob/v2.0.14/docs/compatibility/release-verification-2.0.14.json)。

提供 Apple Silicon（arm64）macOS 安装包，最低 macOS 14；本次没有修改 Windows 适配器或发布 Windows 安装包，也不要求更换 X Nook。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
