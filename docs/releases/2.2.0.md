# X Island v2.2.0 — 任务摘要、图标风格与交互修正

日期：2026-11-21

本次为中版本更新，重点是「任务摘要」：让卡片能说清楚一个会话到底做了什么、改到哪一步。

## 任务摘要

### 从流水到人话

此前卡片的摘要区来自两条路：

- Devin / CodeBuddy 在 hook 里自带 `summary`，直接显示
- 其余客户端没有摘要，退回「最近：Read · 路径」+「12 个工具 · 4m 32s」

第二条基本看不出做了什么。现在补上模型归纳：会话完成时把「任务描述 + 最近 30 条工具事件（含命令输出摘要）」交给模型，输出 3-5 行中文：

```
修复卡片点击跳转时点错会话
- 移除摘要区展开按钮，改到底部操作行
- 面板展开期间冻结列表顺序
状态：已完成，构建通过
```

摘要写入会话记录，卡片标题显示为「摘要」；模型不可用时继续用事件归纳，标题为「回顾」。这两个标题可以直接区分来源。

### API Key 与本地模型

- 云端 key 在设置内输入，存入 **Keychain**（`dev.xisland.llm-summary`），不写偏好文件
- 未填 key 或请求失败时自动回退本地 Ollama，再回退事件归纳
- 本地 Ollama 有独立引导：未安装 → 获取入口；已安装无模型 → 一键下载；就绪 → 显示模型名
- 模型可下拉选择已安装的，右侧菜单可下载推荐模型（`qwen2.5:3b` / `1.5b`、`qwen3:1.7b`、`llama3.2:3b`、`gemma3:1b`）
- 「模型驻留」控制生成后模型在内存保留多久：30 秒（默认）/ 2 分钟 / 5 分钟 / 一直保留

### 什么时候生成

| 触发 | 说明 |
|---|---|
| 会话首次完成 | 立即后台生成 |
| 再次完成且工具事件增加 | 重新生成并覆盖，保证摘要不过时 |
| 面板展开 | 即时补最近 1 个 |
| 应用启动后 8 秒 | 后台串行补齐历史，每次最多 20 个 |
| 每 10 分钟 | 检查是否还有未补的会话 |
| 右键「生成摘要」 | 手动触发，跳过去重 |

生成过程不阻塞界面：完成瞬间显示「回顾」，模型返回后自动换成「摘要」。

### 对 3B 模型的适配

qwen2.5:3b 对长提示词和示例敏感——早期版本把示例当输入，输出了完全无关的内容。现在的提示词只保留三句约束，并给出同类任务的短示例；代码层再做一道清洗：剥掉「第 1 行」「中间行」这类标签，缺少状态行时按真实状态补齐。

## 图标风格

设置 → 显示 → 外观 → **图标风格**，三选一：

| 选项 | 效果 |
|---|---|
| 吉祥物 | 自绘形状 + 表情动画（原有行为） |
| 软件 Logo | 按 bundle id 取对应客户端的真实图标，找不到时回退吉祥物 |
| 自定义图片 | 选一张本地图片，统一转 PNG 存应用支持目录 |

提醒动画同步调整：由「上跳 + 旋转」改为整体缩放弹跳（1 → 1.18），三种图标都会跟着跳；运行中的呼吸光晕也补到了 Logo 与自定义图。

## 交互修正

### 点击跳转

- **摘要区点击不跳转**：原因是摘要右下角的展开控件会消费点击且只展开。移除后摘要正文回归整卡跳转
- **展开/收起**：改为独立按钮，放在底部操作行「继续下一步」左侧，仅在摘要超过 3 行或 120 字时出现
- **点击时列表位移导致跳错会话**：面板展开期间冻结排序，新会话排在末尾，收起后恢复实时排序

### Codex 跳转

`codex://threads/<id>` 只对本机存在的 thread 有效，直接打开会显示「Chat unavailable on this computer」。现在跳转前先查 `~/.codex/session_index.jsonl`：找不到就降级为激活 ChatGPT 并打开项目目录，不再进入错误页。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.

## 辅助功能权限

「继续下一步」需要辅助功能权限才能自动粘贴。应用内 **设置 → 权限** 集中展示状态并提供授权入口；更新版本后需重新拖入一次（adhoc 签名的固有限制，应用会自动清理旧条目）。未授权时指令仍会复制到剪贴板，手动 ⌘V 后回车即可发送。
