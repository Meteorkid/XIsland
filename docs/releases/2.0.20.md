# X Island v2.0.20 — 精简单卡、活跃窗口与展开可靠性

日期：2026-11-17

本版集中处理「面板看起来太长、展开不完整、提醒会打断或被忽略」三类日常问题，并把展开高度从估算改为读取真实布局。

## 会话卡片「仅摘要」

- 偏好设置 → 显示 → 「会话卡片只显示摘要」。
- 隐藏提示词、回复流、当前工具与工具调用列表，只保留标题与摘要。
- 客户端未上报摘要时，显示「摘要（本地）」：最后一条工具活动、工具次数、用时。
- 本地摘要不调用任何模型，离线可用；标注「本地」以区别于客户端摘要。

## 活跃窗口

- 面板默认只显示最近 **24 小时**内有对话的会话。
- 设置中可选 `6h / 12h / 24h / 72h / 全部`。
- 右键会话可「保留在活跃列表」，保留项不受时间窗口限制；再次右键取消。
- 搜索不受窗口限制，旧会话仍能找回；待审批/待回答的会话永远显示。
- 列表为空时显示空状态与「显示全部会话」按钮。

## 自动展开与收起

- 任务完成、审批/问答/计划审核时自动展开面板，默认开启，可分别关闭。
- 同一批提醒在 80 ms 内合并，只展开一次；审批优先于完成。
- 完成提醒展开后停留 **6 秒**自动收起；指针仍在面板上时顺延，离开后再收。
- 审批提醒不自动收起，直到处理或手动关闭。
- 可选「在所有桌面与全屏应用上强制显示」。

## 展开可靠性

- 修复程序化展开被 `expandPending` 守卫丢弃的问题，改为小幅重试直到可以展开。
- 面板高度不再按每卡 80pt 估算，改为读取 `LazyVStack` 布局后的真实高度；展开后窗口会随内容校正。
- 展开 recap 的「显示更多」时，面板高度同步增长。

## 视觉

- 移除卡片随指针距离缩放/抬升的动画，鼠标扫过不再引起卡片跳动；hover 背景高亮保留。

## 修复

- 永久授权不再显示「可离线使用至」的具体日期。该日期是离线凭证刷新周期，不是授权期限；现显示为「永久有效 · 无需续期（联网时自动刷新离线凭证）」。
- 一个月、一年与试用授权仍显示使用期限与离线期限。

## 原有使用规则

安装包继续提供免费下载，首次启用联网后开始完整的 **14 天试用**。用户可以选择一个月、一年或永久授权，每份产品授权最多同时使用 **3 台设备**，支持解绑换机。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
