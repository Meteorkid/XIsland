# X Island v2.0.12 — 任务提醒、统一收起与连续双岛切换

日期：2026-10-27

本版新增了任务完成与交互提醒，将自动收起简化为一个开关和一个延迟，并改进了与 X Nook 的双指切换、回弹和果冻动画。

## 新增：任务提醒

- 新增了默认开启的“任务提醒”，可从展开面板的铃铛按钮、右键菜单或“设置 → 通用”统一开关。
- 为新确认完成的任务增加了自动切回 X Island 和吉祥物双跳提醒，动画结束后继续保留“完成未查看”标记。
- 为审批、提问和计划审阅增加了自动切回并展开，用户仍需主动批准、拒绝或回答。
- 为只能观察状态的客户端保留了总览与跳转入口，等待状态不会被误显示成可在岛内操作的审批能力。
- 为短时间集中到达的提醒增加了合并与交互优先处理，重复事件、历史回放和已解决的旧请求不会反复切回。
- 将未查看的完成任务优先放入最近任务图标候选，待处理请求仍保持最高优先级。
- 让吉祥物提醒仅在岛可见时短暂播放，并遵循“减少动态”和“禁用动画”设置。

自动显示岛、展开列表和悬停都不会把完成结果标为已查看；打开任务详情、成功主动跳转到对应会话或显式确认后，才沿用已有查看确认规则。最近任务数量和完成会话保留期继续生效，未查看标记不代表无限期驻留。

## 变更：一个自动收起开关、一个延迟

- 将原来三种容易混淆的收起延迟统一为“自动收起”开关和“离开后的延迟”，普通展开、悬停展开、空面板及交互处理结束均使用同一规则。
- 将延迟范围统一为 **0–600 秒**，新安装默认开启并等待 **3 秒**。
- 修正了 0 秒的含义：鼠标离开面板和岛后，首次检测到外部位置即开始收起动画，不再把 0 当作关闭功能。
- 保留了鼠标在面板或岛内时不收起、重新进入取消倒计时、再次离开重新计时的行为。
- 保留了审批、提问、计划审阅及只读观察等待状态的展开保护，等待用户处理时不会被 0 秒设置收起。
- 为关闭自动收起保留了原延迟数值，再次开启无需重新设置。

**0 秒表示不额外等待，不表示动画瞬间结束。** 若通过快捷键打开面板时鼠标原本就在外部，且没有待处理交互，也会在首次检测到外部位置时开始收起动画。

### 旧设置如何迁移

| 旧设置 | 升级后的行为 |
| --- | --- |
| 原“自动收起延迟”已保存有效值 | 优先沿用该值，包括 0 秒。 |
| 原“移出面板后收起”明确为 0，表示关闭 | 保留关闭意图，新“自动收起”开关保持关闭。 |
| 原主延迟未保存，但普通移出延迟有有效值 | 沿用普通移出延迟。 |
| 没有已保存的旧值 | 使用开启、3 秒的默认值。 |
| 已经保存过新版开关或延迟 | 保留新版选择，不再被旧值覆盖。 |

例如，旧版“自动收起延迟 0 秒、移出面板后收起 5 秒”会统一为 **开启、0 秒**。迁移保留了旧字段，未清空偏好或历史记录；具体规则见 [统一自动收起说明](https://github.com/Meteorkid/XIsland/blob/v2.0.12/docs/plans/2026-10-26-unified-auto-collapse.md)。

## 变更：连续双岛切换

- 增加了与 X Nook 的连续双页预览，双指横滑时逐渐露出另一款岛的部分内容，松手后再决定切换或回弹。
- 让不同尺寸的岛在切换中连续调整外壳宽高，并让两页内容共享位移，减少大小差异造成的割裂。
- 保留了短滑松手回弹、跨零反向和左右切换，并让取消操作保持当前岛。
- 为对端未运行、旧版本、尚未就绪或显示环境不适合预览的情况保留了安全回退，松手确认后再打开和切换。
- 为已播放完整预览的交接去掉了第二次滑入动画，避免画面到达后又重复移动。

连续预览建议配套 **X Nook 1.3.24 或更新版本** 使用。设置入口的普通切换与双指预览共用安全交接规则；目标尚未可见时，来源岛继续保留。

## 修复

- 修复了松手切换后旧岛先恢复画面再隐藏、造成短暂闪回的问题。
- 修复了背景分层后的重复动画与插值问题，恢复了悬停、展开和收起时果冻形变的连续传递。
- 修复了审批或提问只显示 X Island、未正确让另一款岛隐藏而可能重叠的问题。
- 修复了过时的切换请求或延迟回调在提醒出现后再次抢走显示权的问题，同时保留了用户之后主动切换的能力。
- 移除了仅因 X Nook 进程存在就在审批处理后自动返回它的行为，避免处理完立即被切走。
- 修复了完成提醒遗留屏幕锚定、以及提醒结束后未及时恢复原全屏隐藏设置的问题。

## 升级与兼容

本版提供 **Apple Silicon（arm64）macOS 安装包，最低 macOS 14**，VS Code 配套扩展维持 **1.0.1**，复用上一版公开发行的相同扩展包。

本次未修改 Windows 源码，也未新增 Windows 安装包。正在其他工作区开发的授权模块、X Nook 布局方案和媒体氛围功能未纳入本版。

当前 macOS 安装包仍为 **ad-hoc 签名**，尚未提供 Developer ID 签名或 Apple 公证；已有客户端信任、任务历史、笔记和托盘数据无需重置。

- 已验证独立进程之间的新旧切换请求判定，以及隔离场景下的取消、回弹、请求替换、交互保护、提醒去重和零延迟迁移。
- 已在本机安装候选上验证 0 秒迁移、自动收起开关、任务提醒铃铛、对端未运行时启动，以及两端设置入口的双向切换。
- 已核对安装后的数据库完整性和旧记录保留，并确认 15 项客户端配置／桥接文件及 X Nook 的笔记、托盘和偏好未变化。

**仍待验收：**真实鼠标停留／移出手感、双指停在半程的连续效果，以及真实客户端完成、审批和提问触发后的自动切回、跳跃与展开。实际 FPS 未测量，不以单元测试、静态画面或设置按钮切换代替这些验证。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
