# X Island v2.0.8 — 软件吉祥物、任务配色与完成未查看

这次让灵动岛中的图标同时表达三个信息：**造型识别软件，颜色和编号识别聊天／任务，表情和角标识别状态**。多个客户端、多个任务并行时，不再全是同一张机器人脸。

## 每个客户端有自己的角色

- 31 个已支持客户端都有独立轮廓，覆盖收起态、会话卡片、阻塞列表和授权／回答／计划审查面板。
- 现有圆角终端机器人只给 **Codex**；其他示例包括 Claude Code 螃蟹、Gemini 四角星、Cursor 指针、WorkBuddy 公文包、Kimi 月牙、DeepSeek 鲸鱼、Roo 长耳角色和 PearAI 梨形角色。
- 既有 Hermes 类型保留独立预留造型，**不代表新增 Hermes 接入支持**。
- 这些是 XIsland 自定义角色，不宣称是各客户端的官方吉祥物，也不改变既有客户端适配能力。

![软件造型和状态预览](https://github.com/Meteorkid/XIsland/releases/download/v2.0.8/mascot-guide-dark.png)

## 不同聊天／任务固定颜色与编号

- 这里的“窗口”指**聊天或任务标签页**，不是操作系统窗口编号，也不会把当前焦点窗口猜测当成真实归属。
- 每个客户端内按任务首次出现分配独立编号；同一任务的状态变化、标题变化和列表重排不会改变配色。
- 身份映射会保留到下次启动，不会因为近期缓存淘汰而给旧任务换号。
- 采用 12 色循环，颜色重复时仍由编号区分，避免仅凭相似颜色猜任务。
- 对具有稳定原生任务身份的观察来源，扩展重载后的同一任务继续使用原配色和编号。
- 图标提示增加了客户端、任务号、状态和聊天标题；嵌入式代理的请求发起者保留自己的软件造型与编号空间。

![Codex三个任务：运行、等待回答、完成未查看](https://github.com/Meteorkid/XIsland/releases/download/v2.0.8/codex-task-states.png)

## 表情表达状态，停止动画也能识别

| 状态 | 表达方式 |
|---|---|
| 运行中／思考中／压缩中 | 睁眼微笑／抬眉／抿嘴 |
| 等待授权 | 平眉闭口与锁标记 |
| 等待回答 | 睁眼圆口与问号 |
| 等待计划审查 | 睁眼圆口与文档标记 |
| 错误 | 交叉眼、下弯嘴与感叹号 |
| 已完成未查看 | 开心表情与持续星标 |
| 普通完成 | 平静微笑与勾号 |
| 空闲／完成未确认／状态未知 | 休息表情，后两者保留相应的不确定标记 |

主体配色不随状态改变。系统或应用开启减弱动画时，锁、问号、错误和未查看标记仍然显示。原生事件仅能证明空闲或完成未确认时，不会为了表情把它伪装成已完成。

## 完成结果的“未查看”独立记录

- 新一轮明确完成时标为未查看；重复结束事件和历史重放不会反复提醒。
- 打开该任务详情／展开摘要、主动跳转到任务，或选择“标为已查看”后确认当前完成版本。
- 展开总列表、鼠标悬停、自动选中以及仅显示吉祥物不会清除标记。
- 同一聊天开始新一轮工作后，会在下一次明确完成时重新产生未查看提醒。
- 确认动作绑定完成时间，旧历史行或迟到的异步操作不能确认之后的新结果。
- 历史页显示未查看提示并提供显式确认入口；现有任务滞留、归档和历史保留策略保持不变。

## 界面与数据兼容

- 在“**设置 → 显示 → 收起态模块 → 吉祥物识别图例**”查看全部角色、任务配色和状态含义。
- 已完成未查看提示移到卡片标题下方，避免挤压右侧标签；浅色外观增加了图标对比。
- 历史库追加可选查看标记，旧记录没有该字段时仍显示普通“已完成”，不把“未记录”说成“用户已经查看”。
- 升级首次打开历史库前会建立本次专用备份，并保留原有备份；若备份校验失败，会停止容器初始化。
- 全历史 JSON 保留该字段的 `true`／`false`／`null`；单会话 JSON 同步支持新字段，并兼容旧文件缺失字段。
- 回退旧版本前应先退出应用，并使用对应的升级前数据库备份恢复；仅替换旧 App 不应被当成已完成数据库回退。

## 验证与发行范围

特性源码回归 **1556 项：1543 通过、13 按条件跳过、0 失败**；最终视觉检查和 Release 构建通过。覆盖 32 个已知类型的独立映射、Codex 专属造型、20pt 轮廓、5000 个既有身份保持、旧 schema 迁移、保存恢复、确认版本保护和导出兼容；31 个已支持客户端与 1 个预留类型明确区分。

已检查深浅外观、收起态、状态图例和未查看卡片。打包后再核对版本、架构、签名自洽性与校验和，并做隔离接入与数据验证。详情见 [2.0.8 发行验证摘要](https://github.com/Meteorkid/XIsland/blob/v2.0.8/docs/compatibility/release-verification-2.0.8.json)。

本版面向 Apple Silicon（arm64），最低 macOS 14；VS Code 配套扩展维持 **1.0.1**，已有 1.0.1 用户不需要因本次图标更新重新安装扩展。Windows 没有新安装包。

当前仍为 ad-hoc 签名，尚无 Developer ID 签名、公证或完整双向认证；本版不宣称解决此前尚未关闭的发布者身份与同用户假服务端风险。真实厂商客户端闭环、VoiceOver 实际朗读、持续原生帧率和外接多屏仍需单独验收。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
