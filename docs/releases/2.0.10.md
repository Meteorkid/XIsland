# X Island v2.0.10 — 精确会话跳转与悬停收起修复

本版修复了点击任务后只激活软件、未定位对应聊天或标签页的问题，新增按会话身份发起的跳转与明确的失败提示；同时统一了自动收起行为，让鼠标停在展开面板或岛内时保持展开，离开后再按设置计时。

## 按对应聊天和终端标签发起跳转

会话列表、详情、Agent Flow 和待处理请求使用同一套跳转与结果反馈；同一项目目录中的不同聊天会按各自身份定位。

| 客户端 | 本版已实现的定位方式 | 使用条件 |
| --- | --- | --- |
| Codex 桌面 | 使用原生线程链接打开指定聊天 | 需要有效的原生线程 UUID，目前覆盖本地线程 |
| Cursor | 使用原生 agent 链接打开指定聊天 | 需要对应的原生会话 ID，目标须能被客户端找到 |
| WorkBuddy | 使用原生聊天链接打开指定任务 | 覆盖已核验的本地命令 hook 会话 |
| iTerm2 | 按唯一会话 ID 或 TTY 选择对应分屏、标签和窗口 | 必须找到唯一匹配的终端会话 |
| Apple Terminal | 按 TTY 选择对应标签和窗口 | 需要可用的 TTY 标识，旧记录可能缺少该信息 |
| WezTerm | 按 pane ID 选择对应终端分屏 | 需要桥接上报 pane ID，且导航命令成功执行 |
| kitty | 按 window ID 选择对应终端窗口 | 需要桥接上报 window ID，且远程控制可用 |

- CLI 任务优先使用实际终端宿主，运行在终端里的 Codex 不会因为名称相同就改跳 Codex 桌面。
- 子任务使用所属父会话的身份和终端信息，父会话已不存在或归属异常时会显示原因。
- 补充了 WezTerm、kitty 和 TTY 定位信息的采集，供新收到的任务事件使用。
- 缺少标识、客户端未安装、自动化权限被拒绝或命令执行失败时，会保留当前面板并显示具体提示。
- 尚无已核验精确路由的客户端及 tmux 会明确提示无法定位，不再按工作目录、前台窗口或第一个窗口猜测目标。

VS Code Local 等客户端仍可使用原有任务观察能力，但本版没有为所有已接入客户端增加精确聊天跳转；支持范围以上表为准。

## 跳转结果与“完成未查看”保持一致

- 点击跳转后，界面会等待精确导航请求的处理结果，失败不会直接清除“完成未查看”或执行跳转后的收起动作。
- 原生聊天链接被系统接受、或终端定位成功后，才执行本次主动跳转的查看确认及相应界面回调。
- 等待跳转期间任务开始并完成新一轮时，旧请求不会把新的完成结果标成已查看。
- 忽略重复回调和已离开视图的迟到回调，避免一次点击多次处理。
- 打开灵动岛内的任务详情仍按原约定视为已查看。

桌面链接被接受表示已向指定客户端发出带会话 ID 的请求；聊天已删除或客户端无法找到它时，仍可能由客户端显示错误。

## 鼠标离开后才开始收起倒计时

- 鼠标停在展开面板或岛内时保持展开，包括静止阅读和在面板、岛之间移动。
- 倒计时从本次离开面板和岛时开始，长时间悬停后离开也会等待完整延时。
- 重新进入立即取消倒计时，下一次离开重新计时。
- 隐藏、重新显示、拖动、等待授权或回答，以及修改延时设置时，会清除旧倒计时。
- 更新了设置说明，原有偏好继续保留，无需重新配置。

三项设置按各自适用条件共同工作：

| 设置 | 适用情况 |
| --- | --- |
| 自动收起延迟 | 交互处理完成后，鼠标已离开面板和岛 |
| 移出面板后收起 | 面板展开且鼠标已离开面板和岛 |
| 鼠标离开后收起 | 悬停触发展开，或普通展开面板中已无会话，且鼠标已离开 |

**多项同时适用时，采用最短的正延时；设为 0／“永不”只关闭对应规则。** 例如适用的两项延时分别为 3 秒和 10 秒时，离开后按 3 秒收起；只关闭其中一项不会同时关闭其他规则。

## 验证结果

- macOS 完整 XCTest **1,619 项：1,602 通过、17 项条件跳过、0 失败**。
- 最终定向回归 **91 项：90 通过、1 项既有时间采样测量条件跳过、0 失败**。
- 本轮 macOS Release 构建通过，临时鼠标诊断代码已从生产源码移除。
- 隔离原生界面检查确认：点击缺少身份的会话后显示具体原因，面板未因跳转失败立即收起。
- 用户使用物理鼠标手工确认悬停行为符合预期：在面板内停留至少 5 秒保持展开，离开面板和岛后按所设约 3 秒延时收起。

回归覆盖同目录多聊天、无效身份、链接编码、CLI 宿主优先、旧 Terminal 标识、父子会话、迟到回调、新完成记录保护、命令失败与超时，以及鼠标重入、设置变化和窗口可见性。

Codex、Cursor、WorkBuddy 的桌面链接已完成本机原生处理代码静态核验和路由测试；原生控制工具限制了对 Codex 应用的读取与操作，因此本轮没有将 Codex 实际页面切换记为自动实机通过，其他客户端和终端的真实多会话切换也尚未逐项验收。多屏、睡眠唤醒仍需单独验证；收起时刻可能受 0.2 秒鼠标采样和主线程调度影响。

详见 [导航与悬停验证记录](https://github.com/Meteorkid/XIsland/blob/v2.0.10/docs/verification/2026-10-24-navigation-hover.md) 和 [客户端协议核验](https://github.com/Meteorkid/XIsland/blob/v2.0.10/docs/verification/2026-10-24-session-jump-protocols.md)。条件跳过的测试没有计为通过，自动化工具的虚拟点击也没有代替物理鼠标验收。

## 升级与下载

本版提供 **Apple Silicon（arm64）macOS 安装包，最低 macOS 14**。从 2.0.9 升级无需清空任务或历史，已有收起偏好继续使用；旧任务缺少终端定位信息时，可在已支持的客户端中重新运行一轮任务，让桥接采集新的标识。

VS Code 配套扩展维持 **1.0.1**，本批未修改 Windows 源码，也没有新增 Windows 安装包或 Windows 实机验收结论。

当前 macOS 包仍为 ad-hoc 签名，尚未提供 Developer ID 签名或公证。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
