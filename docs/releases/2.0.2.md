# X Island v2.0.2 — 历史数据、运行流畅度与可靠性更新

本次更新集中改善长会话和大历史库的使用体验，补齐历史分页、搜索和完整导出，并加强审批、自动配置、退出保存和更新失败时的数据保护。

本次提供 **macOS 14 及以上、Apple Silicon（arm64）** 安装包；Windows 源码修复同步提交，仍为独立的 **0.1.8 开发预览**，本次不发布新的 Windows 安装包。

## 历史记录与统计

- 新增了每页 100 条的历史分页，修复了旧记录受列表上限影响而无法完整查看的问题。
- 新增了全库搜索，支持提示词、工作目录、客户端名称与简称、模型和会话 ID，并支持中文及大小写匹配。
- 修复了删除末页记录后停留在无效页的问题，删除后会回到有效页。
- 新增了全历史 JSON 导出，保留完整会话、工具输入输出和聊天内容，不受当前搜索结果或分页限制。
- 导出完成后增加了实际会话数量、保存路径和 Finder 定位入口。
- 移除了统计只读取前 5,000 条历史的限制，并修复了镜像会话跨批次重复统计和历史变化后未及时刷新的问题。
- 补齐了历史保留期的启动检查和每小时维护，并保留未完成会话及“永不清理”设置。
- 为读取、统计和导出失败增加了明确提示与重试，避免把失败显示成空历史或导出成功。

导出格式和文件保护规则见[历史导出说明](https://github.com/Meteorkid/XIsland/blob/v2.0.2/docs/history-archive.md)。导出目前不提供导入功能，也不会恢复可执行的审批连接。

## 性能与长期运行

- 将历史查询、统计、导出、清理和软件接入扫描移到了后台，减少磁盘与目录扫描占用主线程的时间。
- 将生产会话保存改为串行后台事务，只在真实保存成功后确认完成，降低长会话写盘对界面响应的影响。
- 改为优先保存变更的工具和聊天记录，并修复了旧保存回执覆盖新变更的风险。
- 为刷新、搜索和清理增加了代次与取消保护，避免过期后台结果覆盖用户的新操作。
- 缓存并限制了最近活动的候选数量，减少频繁重绘时的重复整理。
- 调整了鼠标轮询：隐藏或遮挡时暂停，闲置时降频，接近并移动时恢复高频响应。
- 保留了展开、收起和悬停果冻动画，并继续遵守系统与应用的减少动态效果设置。

## 审批、问答与数据保护

- 修复了审批摘要可能遮蔽实际命令的问题，详情保留完整的原始参数、路径和请求内容。
- 严格区分了 Claude 内置问答与第三方同名工具，避免把不受支持的工具误当作可直接回答的内置问答。
- 移除了按相似问题文本自动复用旧答案的行为，每个新请求都需要独立确认。
- 为审批发送增加了即时反馈和重复点击保护，过期请求不再继续发送。
- 修复了保存失败时会话可能过早移除的问题，失败记录会保留以供重试。
- 退出时增加了在途审批和已接收写入的等待，历史无法保存时取消退出并保留当前数据。
- 修复了 Kimi 后台审批事实、旧回执与新写入之间的顺序问题，观察中断时继续保留未确定的状态。

## 自动配置与授权体验

- 改进了统一接入窗口的后台扫描、配置准备、刷新和取消行为，避免界面等待和旧状态回写。
- 修复了普通刷新打断批量准备后丢失后续重试意图的问题，关闭或明确取消后则停止继续准备。
- 加强了配置写入前的内容与文件身份检查，并为成功替换保留受限权限的同目录备份。
- 加强了插件文件归属校验，用户修改或追加过的接入脚本不再仅凭首行标记被覆盖或删除。
- 修复了非默认 `CODEX_HOME` 的误写风险，当前不支持自动管理的自定义目录会明确提示，而不会改写默认配置。

原客户端要求的首次信任仍需用户确认；本次不会绕过客户端授权，也不把“已收到活动”当作所有功能已经完成验收。

## 更新与额度显示

- 加强了图形更新和命令行更新的校验、暂存、替换与回滚，失败时优先保留可恢复的旧版本。
- 为命令行升级增加了官方发行地址、版本、DMG 资产和 SHA-256 的一致性检查。
- 修复了保存失败取消退出后，更新安装器仍遗留在后台等待的问题，更新现在会先确认写入完成，再启动安装器，失败时清理并允许重试。
- 阻止了重复启动更新任务，并协调普通退出与更新退出，避免安装器就绪前提前结束应用。
- 停止了通过自动发送模型生成请求来探测额度的行为。
- 区分了已用 Token、账户余额及币种、API 可访问性和未知额度，避免把已用量或金额误显示成剩余 Token。
- 修复了关闭供应商额度读取后仍启动不必要读取，以及终端宿主缺少独立应用标识时的跳转边界问题。

## 界面细节

- 修复了短权限审批面板过矮、批准和拒绝按钮需要额外滚动才能看到的问题。
- 同步了面板目标尺寸、实际内容高度和动画缓存，普通会话列表继续保持紧凑。
- 补齐了收起态客户端图标的回退显示和客户端状态的无障碍标签。
- 统一了设置窗口入口与 Command+逗号快捷键，减少重复或空白设置窗口。
- 修复了设置窗口内普通键盘输入误处理后台审批的风险，并保留回车不默认批准、Escape 退出详情的行为。

## Windows 源码同步

- 同步了审批真实参数展示、Claude 问答身份保护与损坏设置缓存恢复。
- 增加了会话容量预算、超限反馈和有界文件读取，保留已有历史与审批。
- 为相同 revision 复用冻结会话快照，减少多窗口订阅时的重复复制。
- 提交了 Windows CI 与相关浏览器交互回归；此前未发布到 main 的 Copilot CLI、Pi 和模型筛选源码也包含在本次同步中。

## 验证范围与已知限制

最终本地回归：**1387 项 Swift 功能测试通过、0 失败**；另外 5 项按需性能/长稳入口在全量运行中跳过并沿用独立证据。编译桥接 **127 场景**、WorkBuddy 导出 **11 事件**、打包 App 的 Codex 合成生命周期、CLI 升级 **22 项**均通过；Windows 本地 **603 项 TypeScript、52 项浏览器交互、26 项 Rust 核心/IPC 与 17 项联动协议测试**和 Windows x64 桌面交叉编译通过。

发布前的最终回归、安装包校验及源码绑定结果见[2.0.2 验证摘要](https://github.com/Meteorkid/XIsland/blob/v2.0.2/docs/compatibility/release-verification-2.0.2.json)。

- 固定存储测试版本完成了真实 **28,806.605 秒**长稳，累计 **25,140 个唯一事件**，数据库完整性和完整导出逐项核对通过。
- 50,000 事件的生产后台保存基准中，总事务 p95 为 **261.68 ms**，主线程模拟交互回调额外延迟 p95 为 **1.08 ms**；每档 5 次检查点，这不是实际 FPS 或物理键盘到显示的端到端延迟。
- 原生隔离测试已检查审批按钮可见性、部分键盘与设置交互，以及 60Hz / ProMotion 模式下的展开收起。
- **VoiceOver 实际朗读与完整焦点顺序、实际连续帧率和外接多屏仍未完成验收**；目前属于证据缺口，不代表已经确认这些功能故障。
- 8 小时结果绑定固定存储代码版本，之后的界面、更新协调和测试仪器补丁由回归验证，未宣称最终 GUI 整版重新完成了 8 小时长稳。
- 真实 AI 客户端闭环、Windows 安装升级、WebView2、输入法和多 DPI 设备验证仍在继续，配置或模拟事件通过不等同于所有客户端实机兼容。
- macOS 包沿用 **ad-hoc 签名**并验证签名完整性，尚无 Apple Developer ID 签名或公证。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
