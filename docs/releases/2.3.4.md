# X Island v2.3.4 — 恢复 Ed25519 签名的应用内更新

日期：2026-11-28

2.3.4 修复 2.3.0 引入的 ad-hoc 更新自锁：自动更新不再强制要求 Developer ID Team ID，改为验证独立的 Ed25519 更新清单签名。DMG、清单和签名文件一起发布；更新器与安装脚本都会校验版本、SHA256 和签名，防止下载包在传输或发布渠道中被替换。

这个版本本身仍然需要**手动安装一次**。从 2.3.4 开始，后续版本可以在应用内更新。

## English summary

X Island 2.3.4 replaces the Team-ID-only ad-hoc update gate with a pinned Ed25519 update signature. The running app verifies a signed manifest before mounting the DMG, and the post-quit installer re-verifies the manifest signature, version, and DMG SHA256 before replacing the app. This restores in-app updates for ad-hoc builds without accepting arbitrary ad-hoc update payloads. The first installation of 2.3.4 must still be performed manually; later releases can use the in-app installer.

## Integration changes

None. The integration matrix remains **35 source entries: 30 active and 5 retired-with-history**. No AI client integration is added, removed, or re-classified.

## 一、修复内容

- 新增 `UpdateSecurity` 模块：定义更新清单 schema，并用 CryptoKit `Curve25519.Signing` 校验 Ed25519 签名。
- 更新清单包含 `schema`、`version`、`dmg`、`sha256`、`key_id`；签名覆盖清单原始字节。
- App 的 Info.plist 写入 `XIslandUpdatePublicKey` 和 `XIslandUpdateKeyID`，公钥随 App 分发，私钥只保存在发布机。
- 更新器在下载 DMG 前先验证清单签名，下载后校验实际 DMG 的 SHA256、版本号和 DMG 文件名。
- GitHub API 匿名配额耗尽时，从 `releases/latest` 跳转得到的 tag 直接构造 DMG、manifest 和 `.sig` 的 Release 下载地址，不再因为拿不到 API 资产列表而失去安装按钮。
- 安装脚本在 App 退出后再次调用 `xisland-update-verify`，复查清单签名与 DMG SHA256，并校验待替换 App 的版本号。
- 移除“必须有 Team ID 才能更新 ad-hoc 包”的自锁；没有清单签名且没有 Team ID 时仍然 fail closed。
- 保留 `codesign --verify --deep --strict`，继续校验 App 包自身完整性。

## 二、安全边界

Team ID 校验仍受支持：如果构建时配置了 `X_ISLAND_UPDATE_TEAM_ID`，安装脚本会额外校验 Team ID 必须匹配。没有 Team ID 的 ad-hoc 构建则依赖独立的 Ed25519 更新公钥；两者都没有时不会自动安装。

更新公钥不是秘密，可以随源码和 App 发布；更新私钥不能进入仓库，也不应上传 CI。发布机丢失私钥后需要生成新密钥对并发布一个带新公钥的版本，旧版本无法验证新密钥签出的清单。

## 三、验证

- `UpdateSignatureVerifierTests` 覆盖有效签名、签名后篡改、版本不匹配、SHA256 不匹配、未知 key ID、畸形签名。
- `AppUpdaterTests` 覆盖安装脚本在替换前再次验签的路径。
- 现有安装事务、回滚、信号恢复、Team ID 分支和 SHA 校验测试全部保留。
- Release 构建、DMG 挂载版本、清单签名和实际 SHA256 交叉校验在发布前执行。

## 四、升级建议

- 2.3.3 及更早版本仍会拒绝 ad-hoc 自动更新；请手动下载本 Release 的 DMG 覆盖 `/Applications/X Island.app`。
- 首次安装 2.3.4 后，后续 Release 需要同时提供 `XIsland-<version>.dmg`、`XIsland-<version>.manifest.json` 和 `XIsland-<version>.manifest.sig`，更新器才会显示可用的应用内安装。
- 覆盖安装后仍需重新授予辅助功能权限。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.

## 辅助功能权限

「继续下一步」需要辅助功能权限才能自动粘贴。应用内 **设置 → 权限** 集中展示状态并提供授权入口；更新版本后需重新拖入一次。未授权时指令仍复制到剪贴板，手动 ⌘V 后回车即可发送。
