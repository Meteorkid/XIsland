# X Island v2.0.23 — 集中权限面板与整卡跳转

日期：2026-11-17

## 集中权限面板

设置页「macOS 隐私」分区改为带状态的权限列表：

- **辅助功能**：实时显示「已允许 / 未允许」，提供「打开设置」与「显示 App」（Finder 定位，可直接拖入列表）。
- **自动化**：标记「按需」，首次跳转终端标签页时由系统询问。
- **通知**：显示授权状态，提供设置入口。
- 底部提供「刷新状态」，并在授权后提示重启应用。

macOS 不允许应用代用户授权，因此面板的作用是提前暴露缺失项、缩短授权路径，而不是一键授权。

## 整卡跳转

修复摘要区点击无反应的问题。此前只有标题与详情包在跳转按钮里，摘要区在按钮之外；在「仅摘要」模式下，卡片大半区域都是摘要，表现为「点了不跳」。

现在除「继续下一步」等独立操作按钮外，整张卡片都触发同一跳转动作，失败时仍在卡片下方显示原因（缺少会话标识、tmux 不支持等）。

## 构建签名

构建脚本新增可选固定签名身份：

- 优先读取 `CODESIGN_IDENTITY` 环境变量
- 其次读取 `~/.xisland/signing-identity` 的文件内容
- 两者都没有时维持 adhoc 签名

用途：本机创建自签名代码签名证书后，本地构建可共用同一身份，macOS 的辅助功能授权不会再因每次构建而失效。发布包仍使用 adhoc 签名，其他用户更新后仍需重新授权一次。

## 原有使用规则

安装包继续提供免费下载，首次启用联网后开始完整的 **14 天试用**。用户可以选择一个月、一年或永久授权，每份产品授权最多同时使用 **3 台设备**，支持解绑换机。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.

## 辅助功能权限

「继续下一步」需要辅助功能权限才能自动粘贴。首次点击时应用会打开设置页并在 Finder 中定位 App，把 X Island 拖入授权列表即可。**更新版本后需要重新拖入一次**（adhoc 签名的固有限制）。未授权时指令仍会复制到剪贴板，手动 ⌘V 后回车即可发送。
