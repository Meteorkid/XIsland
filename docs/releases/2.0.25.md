# X Island v2.0.25 — 提醒停留修正与横条式授权浮窗

日期：2026-11-18

## 完成提醒不再被提前收起

问题：任务完成后面板自动展开，但往往一两秒就收起，来不及查看。

原因是两套收起计时同时运行：

| 计时 | 触发条件 | 时长 |
|---|---|---|
| 提醒计时 | 完成提醒展开 | 6 秒 |
| 指针离开计时 | 指针不在面板内 | 设置中的「指针离开延迟」 |

提醒展开时指针本来就在外面，于是较短的指针离开计时先触发。

现在的规则：

- 提醒计时期间不启用指针离开计时
- 6 秒到期时，若指针仍在面板上，收起权交回指针离开计时，**完全遵循设置中的延迟**
- 把延迟设为 0 秒时，指针离开即收起
- 展开/收起动画未结束时每 0.3 秒重试判定，不会提前收起

## 授权浮窗改为横条

原先是一个 132pt 宽的竖向小卡片；现在改为 560pt 横条：

- 首行：蓝色向上箭头 + 「将 X Island.app 拖到上方列表以允许『辅助功能』」+ 关闭按钮
- 次行：整条可拖动的应用条目（图标 + 「X Island.app（点我拖动）」）
- 浮窗放在系统设置窗口**下方居中**，与「上方列表」的措辞对应；下方空间不足时改放上方
- 拖出的是 `.app` 文件本身，可直接落入授权列表

## 原有使用规则

安装包继续提供免费下载，首次启用联网后开始完整的 **14 天试用**。用户可以选择一个月、一年或永久授权，每份产品授权最多同时使用 **3 台设备**，支持解绑换机。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.

## 辅助功能权限

「继续下一步」需要辅助功能权限才能自动粘贴。应用内 **设置 → 权限** 集中展示状态并提供授权入口；更新版本后需重新拖入一次（adhoc 签名的固有限制）。未授权时指令仍会复制到剪贴板，手动 ⌘V 后回车即可发送。
