# X Island v2.0.13 — 14 天试用与软件激活

日期：2026-10-27

本版接入了软件内的试用和激活机制：安装包可以免费下载，首次启用联网后开始完整的 14 天试用，之后可选择月付、年付或永久使用授权。网站与 GitHub 分发的本版安装包遵循相同规则。

## 试用与激活

- 新增了“设置 → 软件授权”，可以查看授权类型、使用期限和离线使用期限，并输入 XIsland 对应的激活码。
- 为试用提供了完整的 14×24 小时，重新下载或重装不会重新开始服务器已登记的试用。
- 支持了月度、年度和永久激活码；购买适用套餐后，网站会为对应软件分别提供激活码，付款记录和码可在账户中查看。
- 为每份产品授权提供了最多 3 台设备，续费延长原授权期限并沿用设备记录，不重复增加设备名额。
- 增加了本机解绑和网站设备管理入口，换机时可以释放旧设备名额后在新设备激活。
- 支持了管理员赠送的月度、年度和永久授权。

月付和年付按订单的授权期限使用，到期后需要续费；永久授权无需续费。首次试用、激活和解绑均需要联网。

## 离线使用与到期行为

已成功核验的设备可以在显示的离线期限内继续使用，最长为 **7 天**，且不会越过试用或订阅的实际到期时间。永久授权仍需定期联网核验设备状态。

运行期间会定期核验，并在唤醒、回到应用和到期时重新判断权限；暂时断网不会取消仍有效的离线使用期限。服务器明确返回已撤销或已解绑后，客户端会停止放行。

到期后，灵动岛和主要监控服务会停止，购买、输入激活码、历史导出和关于页仍可使用。已有历史与设置不会因为到期被删除；续费或重新激活后可以恢复运行。

## 既有购买与升级

既有有效购买按原有权益迁移：已买断的产品继续永久有效，月付和年付保留原有剩余期限，无需重复购买。升级后请使用**原购买邮箱**登录 [Meteor Store 账户](https://www.imagentx.top/zh/account#software-licenses)，在软件授权区获取 XIsland 对应的激活码，再在软件设置中激活；记录未显示时可联系店主核对订单。

升级时先退出旧版 XIsland，再替换应用。无需卸载后重新安装，也无需清空历史、偏好或已有客户端配置。旧版安装包不会因为网站规则变化自动获得本版的授权机制。

## 修复与兼容

- 修复了系统时间曾被误设到未来、恢复正确时间后仍无法重新核验授权的问题。
- 修复了快速锁定后重新激活时，旧的已取消接入扫描可能丢失新刷新请求的问题。
- 为正式 Release 构建保留了授权门禁，测试启动参数不能开启免授权的监控服务。

本版保留了 2.0.12 的任务提醒、统一自动收起、连续双岛切换和较旧 Swift 编译器的构建兼容修复。提供 **Apple Silicon（arm64）macOS 安装包，最低 macOS 14**；本次未修改 Windows 源码或新增 Windows 安装包。

## macOS 打开提示

安装包仍使用 **ad-hoc 签名**，尚未提供 Developer ID 签名或 Apple 公证。若提示“无法验证开发者”或“Apple 无法检查其是否包含恶意软件”，可在确认官方来源后进入“系统设置 → 隐私与安全性”，按系统提供的“仍要打开”入口操作；若提示“将损坏你的电脑”或“已损坏”，请停止使用并联系店主核对。具体说明见 [官网帮助中心](https://www.imagentx.top/zh/docs/macos-cannot-open-app)。

软件授权凭证的签名校验与 macOS 应用签名是两个不同的检查；本版不会要求关闭系统安全保护。

## 验证记录

授权协议、运行门禁、到期与恢复、错误签名、产品及设备不匹配、断网、时钟校正，以及与双岛预览的兼容性均纳入自动化回归。新合并源码的完整回归共 **1843 项：1824 通过、19 条件跳过、0 失败**，其中共享授权核心 17 项全部通过，并包含 Node 签发、Swift 验签的跨语言检查。

随后合并了测试线程收尾和原生窗口显示前置条件的修复，对应 **13 项连接回归与 5 项窗口回归全部通过**；这些合并未改变产品源码，已构建安装包保持一致。

安装包已使用正式授权公钥和正式网站地址构建，完成了只读挂载、包内逐文件比对、arm64 架构、签名完整性、版本与源码快照核对。机器可读记录见 [2.0.13 发行验证](https://github.com/Meteorkid/XIsland/blob/v2.0.13/docs/compatibility/release-verification-2.0.13.json)。
