# X Island v2.0.22 — 继续下一步、静止面板与徽章收敛

日期：2026-11-17

本版处理三件事：给会话卡片加上「继续下一步」入口；把面板与卡片的所有非必要动效移除，让展开尺寸稳定；把重复的徽章合并为一个。

## 继续下一步

- 已结束或空闲的顶层会话，卡片底部新增「继续下一步」按钮。
- 点击后：复制「继续下一步」→ 激活对应会话窗口 → 自动 ⌘V 粘贴 → 卡片内提示「已粘贴，按回车发送」。
- **不会自动按回车**，发送由用户确认。
- 首次使用需要「辅助功能」权限：点击时会弹出系统授权提示并打开设置面板。未授权时降级为「已复制，请手动 ⌘V」。
- tmux 会话当前无法激活窗口，按钮会返回对应错误提示。

## 面板完全静止

- 移除指针进入面板时的「果冻」缩放，以及 `jellyIntensity` 设置项。
- 移除卡片入场级联、插入/移除转场与列表布局动画。
- 移除展开高度的实时测量：高度只由会话数量与卡片模式（仅摘要 132pt / 完整 220pt）决定，展开后不再随内容或动画变长变高；内容超出上限时列表内部滚动。
- 修复悬停时卡片变高：关闭按钮改为常驻占位、只切换透明度；来源徽章与时长固定宽度，不再被挤压成逐字竖排。

## 徽章收敛

- 卡片主徽章合并为单一「Agent · 任务编号 [· 来源]」。
- 来源与类型同名（例如 WorkBuddy 的 terminal 就是 `workbuddy`）时省略来源，不再出现两个「WorkBuddy」。
- 有区分度的来源（`cursor ide`、`cursor cli`、`codex cli` 等）仍会追加显示。

## 提醒行为

- 自动展开只受「任务提醒」开关控制；减少动态效果、禁用动画、应用隐藏、岛被切换都不阻止展开。
- 提醒展示时补充强制置顶，应对应用刚隐藏或另一个岛刚接管的情况。
- 完成提醒未查看时，收起态吉祥图每 2.4 秒跳动一次，直到查看或标记已查看。
- 完成提醒展开后 6 秒自动收起；指针仍在面板上时顺延。

## 原有使用规则

安装包继续提供免费下载，首次启用联网后开始完整的 **14 天试用**。用户可以选择一个月、一年或永久授权，每份产品授权最多同时使用 **3 台设备**，支持解绑换机。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
