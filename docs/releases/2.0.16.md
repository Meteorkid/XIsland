# X Island v2.0.16 — 通知与自动化、切换显示修复

日期：2026-11-04

本版新增「通知与自动化」设置页，把系统通知、外部推送、不打扰策略、会话生命周期、诊断导出与防休眠集中到一处，全部默认关闭。同时修复了切换应用时岛被误隐藏、菜单项点击无反应等问题。

## 系统通知

- 会话需要审批、完成或出错时可在通知中心提醒；默认只读，不提供任何决定按钮。
- 可在设置中显式开启「允许在通知里直接批准 / 拒绝」；回执需请求 ID 精确匹配，过期或重复点击一律忽略。
- 请求被消费后自动撤回对应通知，避免残留可点击的旧通知。

## 外部推送

- 支持 Bark、ntfy、钉钉、飞书、企业微信、Slack、Telegram 与自定义 Webhook。
- 默认仅在锁屏或屏保时推送；正文出本机前统一脱敏，推送只发文本、不代替审批。
- 每个渠道可单独选择订阅的事件，并提供发送测试（返回真实 HTTP 状态）。

## 不打扰与生命周期

- 锁屏、屏保、显示器睡眠三态独立判断；静默时段支持跨午夜，审批类事件不受静默限制。
- 支持静默目录与子会话抑制；未读事项可按设定延迟追加提醒。
- 30 分钟无活动自动隐藏、同工作目录只保留最近活跃一条；隐藏只影响显示，搜索可找回，待审批与未查看完成的会话永不隐藏。

## 诊断与防休眠

- 一键导出脱敏诊断包：白名单设置、会话状态与日志尾部打包为 zip，渠道地址与历史正文不进入包内。
- 会话感知防休眠：关闭 / 有工作会话时 / 始终三档；低电量且未接电源时自动暂停，宽限期结束后释放断言。

## 修复

- 修复了仅安装、未运行的另一个岛被当作可切换目标，导致本岛让位后无人接管、窗口消失的问题。手势现在只切换到正在运行的对端；无对端时不再隐藏，并有 3 秒兜底恢复。
- 修复了菜单栏「显示岛 / 软件接入 / 检查更新 / 退出」点击无反应的问题（菜单项缺少 target）。
- 修复了声音静默时段读取的键名与设置页写入不一致，导致配置从未生效的问题。
- 修复了推送标题未脱敏、诊断包深路径未裁剪的问题。
- 修复了「已完成但尚未查看」的会话被自动隐藏、观察型来源等待态会话被同目录规则取代的问题。
- 修复了发行包 Info.plist 缺少本地网络权限声明，可能导致伴端无法发现同 Wi-Fi 设备的问题。

## 原有使用规则

安装包继续提供免费下载，首次启用联网后开始完整的 **14 天试用**。用户可以选择一个月、一年或永久授权，每份产品授权最多同时使用 **3 台设备**，支持解绑换机。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
