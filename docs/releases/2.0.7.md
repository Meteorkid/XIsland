# X Island v2.0.7 — 连接稳定性与 VS Code 观察接入修复

本次修复本地连接的资源计数与读取时限，并将 VS Code 配套扩展改为通过原生桥接投递，避免正式身份检查把观察事件挡在面板外。

## 连接更稳定

- **连接配额只归还一次。** 修复了连接关闭或取消后，销毁对象时再次归还配额的问题；此前可能低估仍在使用的连接数量，使 32 个并发连接的限制失效。
- **整条消息共用 10 秒读取时限。** 不再让每个新分片重新获得完整等待时间，避免慢速发送长期占用连接。
- **超时残帧会被拒绝。** 即使已经收到的片段恰好是合法 JSON，也不会把尚未结束的请求当成完整事件。
- 保留了首个换行结束一帧、真正 EOF 结束旧格式消息、大消息读取与请求半关闭后写回审批结果的行为。

## VS Code 配套扩展 1.0.1

- Roo Code 与实验性的 PearAI Roo fork 观察事件改由固定路径的 `di-bridge` 原生进程发送，解决 Node 直接连接与正式进程白名单冲突的问题。
- 保持既有进程身份检查，没有为此开放任意 Node 进程；扩展启动桥接不经过 shell。
- 保留了消息顺序、队尾流式合并、队列大小限制、业务事件与心跳各自的过期时间，以及窗口退出时的有限等待。
- 消息交给桥接后不重放，避免断线时重复记账或重复处理；连接前失败仍可重试。
- 单帧最大 256 KiB，读取与写入共用有限时限，避免异常扩展输入长期占用连接。

## 观察消息与审批保持隔离

- 新入口只允许 Roo Code／PearAI 的六类观察事件，拒绝授权、问答、计划、审批响应和旧式会话结束消息。
- 校验来源命名空间、实例、递增序号字段以及任务派生身份；父子任务必须属于同一观察来源。
- 缺失或错配身份的消息会被拒绝，不能落入旧会话处理路径并清除原生审批待办。
- 扩展仍只观察已支持客户端公开的任务事件；批准、拒绝和回答仍在原客户端完成。

## 升级步骤

1. 先安装 **X Island 2.0.7**，正常启动后核对“设置 → 关于”的版本与桥接状态。
2. 如果使用 Roo Code 或 PearAI 配套扩展，再安装本 Release 附带的 **`xisland-vscode-1.0.1.vsix`**，然后重新加载编辑器窗口。
3. 仅更新 App 不会自动替换编辑器里已经安装的旧 VSIX；**1.0.1 扩展需要 2.0.7 或更新的原生桥接**。
4. 不使用该配套扩展的用户只需更新 App；已有偏好、历史记录和客户端信任继续保留，本版不涉及历史库迁移。

Roo Code 的既有支持范围为 3.54.0；PearAI Roo fork 3.15.3 仍为默认关闭的实验观察入口。两者的真实编辑器加载、模型任务和全部客户端闭环仍需目标环境验收，本版不扩大支持范围。

## 测试与工具改进

- 对关闭、取消、超时、析构和发送竞争增加了配额释放回归，并覆盖慢速分片、超时残帧及合法 EOF。
- 增加真实短命桥接、存活桥接、非批准进程和本机 SSH 进程身份策略测试。
- 隔离 App 联测现可启用完整生产认证规则，避免测试模式跳过身份检查而掩盖问题。
- 修复测试运行时诊断路径的 `/tmp`／`/private/tmp` 别名问题，同时保留原有隔离校验。
- 纳入 2.0.6 发布后提交的集成脚本修复：用独立实例、结构化诊断和临时历史库验证，不再依赖已停写的旧日志或重启正式实例。

源码回归记录为 **1524 项 Swift 测试：1508 通过、16 按条件跳过、0 失败**；扩展 **45 项通过**。正式打包产物另行核对版本、架构、签名自洽性、校验和，以及原生桥接、WorkBuddy 和严格认证的隔离 App 链路。具体结果见 [2.0.7 发行验证摘要](https://github.com/Meteorkid/XIsland/blob/v2.0.7/docs/compatibility/release-verification-2.0.7.json)。

## 安全能力说明

这里更正 2.0.6 更新说明中过于宽泛的表述：当前安装包仍是 **ad-hoc 签名，尚未取得 Developer ID 签名或公证**；发布者 Team ID 校验代码尚未启用。下载来源限制和 SHA256 完整性检查不能替代独立发布者认证。

本地连接目前提供同用户检查与尽力而为的进程路径检查，并非完整双向认证；同用户假服务端风险也没有在本版宣称解决。桥接内容同步不是持续执行时的防篡改保护。应用会自动检查更新，安装仍由用户操作触发。

本次发行面向 Apple Silicon（arm64），最低 macOS 14；Windows 没有新安装包。VoiceOver 实际朗读、持续原生帧率、外接多屏和真实 SSH 远端隧道不属于本轮验收完成范围。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
