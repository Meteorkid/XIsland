# X Island v2.1.0 — 权限体验、跳转可靠性、Trae 适配

日期：2026-11-19

本次为中版本更新，集中在三块：权限授权流程、会话跳转、客户端兼容。

## 权限

### 状态自动刷新

权限页不再需要手动刷新：

- 从系统设置切回应用时立即重新检测
- 停留在权限页期间每 1.5 秒轮询一次
- 辅助功能行显示当前运行路径，便于核对列表里拖入的是不是同一个副本

### 版本更新后自动清理旧授权

adhoc 签名下，每个构建的代码哈希不同。列表里残留的旧条目会让系统显示「已勾选」，但当前进程实际没有权限。

现在的处理：

1. 以「版本号 + 可执行文件修改时间」识别新构建
2. 新构建首次启动时执行 `tccutil reset Accessibility dev.xisland.app`
3. 权限页提示「版本已更新，旧授权条目已清理」
4. 把 App 重新拖入一次即可，无需手动点重置

同一构建的重复启动不会反复清理。

### 救援入口

权限页底部新增两个按钮：

| 按钮 | 作用 |
|---|---|
| 重置授权 | 清空该应用的所有辅助功能条目，用于处理「多条旧条目」 |
| 重启应用 | 自动退出并重新拉起，用于授权生效但进程未重读的少数情况 |

### 授权浮窗

- 改为横条布局：一行说明 + 整条可拖动的应用条目
- 位于系统设置窗口下方居中，与「拖到上方列表」的措辞对应
- 拖拽源改为 NSView 实现：首次按下即可拖、位移超过 3pt 才启动、取消拖拽时浮窗保留
- 补充备用引导：拖拽无效时可用列表下方 `+` 手动选择

## 会话跳转

### 点击终于稳定

两个长期问题：

1. **点摘要/留白不跳转**：跳转按钮此前只覆盖标题区。现在整卡兜底响应点击，内部按钮（继续下一步等）仍优先消费，不会误触。
2. **要点两次**：跳转请求此前不可重入，且等待 LaunchServices 回调期间没有任何反馈。现在可重入、2.5 秒超时复位，点击瞬间显示「正在跳转…」。

### 跳到正确的客户端

Trae 系的 `forAgent` 此前固定返回国际版，导致 Trae CN 的会话被打开到 `Trae.app`。现在按消息到达瞬间的前台应用识别来源发行版，并在 `di-bridge` 侧用父进程链做补充判断。

### 跳到正确的桌面

此前 `activateAllWindows` 会把应用所有窗口提到当前 Space，看起来像「窗口被搬过来」。现在只激活应用，由系统切换到窗口所在的桌面。

### IDE 降级跳转

以下客户端没有会话级 deeplink，点击后改为「切换到客户端 + 打开项目目录」：

Trae、Trae CN、TRAE SOLO CN、VS Code、Windsurf、Zed、Antigravity

客户端已在运行时只切换窗口，不再让 IDE 新开窗口。提示文案会说明「不支持直达会话」。

### 实验性会话定位

对 Trae 额外尝试通过辅助功能树按会话标题定位并点击：

- 命中 → 提示「已在客户端中定位并打开对应会话」
- 未命中（Electron 未暴露 a11y 树）→ 回退到窗口级结果

## 面板排序

由单一状态优先级改为四段式：

| 档位 | 内容 |
|---|---|
| 1 | 待审批：等待授权 → 等待回答 → 等待计划审核 |
| 2 | 完成待查看：刚跑完且未确认的会话 |
| 3 | 运行中：执行工具 → 思考 → 压缩 |
| 4 | 静止：空闲、已查看的完成会话 |

出错会话仍置顶。同档按最近活动时间降序。

### 客户端内查看后自动标记

切到客户端时读取窗口标题，若某个待查看会话的标题出现在标题里，即标记为已查看。标题不含会话名时不做处理，避免误清。

## Trae 适配

### 全局路径更正

官方文档明确：国内版与国际版的全局 Hook 都读取 `~/.trae-cn/hooks.json`。

`~/.trae/hooks.json` 是**项目级**路径（`<项目>/.trae/hooks.json`），不是第二个全局配置。此前把它当国际版全局处理是错的，已回退。

### 旧配置迁移修复

旧版写入的扁平事件（`beforeSubmitPrompt`、`afterAgentResponse` 等）在迁移时，因 `stop` 事件的 `--hook` 参数与当前映射不一致而整体中止。现在只要命令指向本桥接的 trae agent 就会被认领并清理。

### 需要客户端开启 Hooks

配置写入不等于生效。Trae 需要：

1. 在设置里启用 Hooks（首次需阅读安全提示）
2. 完全退出并重启客户端

详细步骤见 [Trae hooks 配置指南](../integrations/trae-hooks.md)。

## 原有使用规则

安装包继续提供免费下载，首次启用联网后开始完整的 **14 天试用**。用户可以选择一个月、一年或永久授权，每份产品授权最多同时使用 **3 台设备**，支持解绑换机。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.

## 辅助功能权限

「继续下一步」需要辅助功能权限才能自动粘贴。应用内 **设置 → 权限** 集中展示状态并提供授权入口；更新版本后需重新拖入一次（adhoc 签名的固有限制，应用会自动清理旧条目）。未授权时指令仍会复制到剪贴板，手动 ⌘V 后回车即可发送。
