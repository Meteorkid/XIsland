# X Island v2.0.0

> 31 项基础接入路线；完整客户端验收范围见下方说明。

## 新增

- 补齐了 Kiro CLI 2.31.0 V3 观察配置导出，并增加了 GLM 在 Claude Code、OpenCode、Cline、Pi 中的模型显示、筛选和历史记录。
- 扩展了多款 AI 编程工具的独立接入方式，并在设置中区分原生 hooks、插件、进程包装器和外部 ACP 通道。
- 增加了 WorkBuddy 插件导出及独立来源识别，避免与 CodeBuddy CLI 会话混淆。
- 增加了 Roo Code 观察扩展、默认关闭的 PearAI 实验入口，以及 Zed、JetBrains 外部 Agent 的 ACP 接入。
- 增加了 Kimi 新版客户端的后台任务、排队、压缩和恢复状态跟踪。

## 修复

- 修复了部分工具停止后被过早判为完成，以及关闭后未执行工具仍显示运行中的问题。
- 修复了迟到事件、重复事件和多轮任务导致的会话身份、工具结果及历史记录错配。
- 修复了 Claude 新会话和首条提示未及时保存，以及 Codewhale 子代理失败、取消和真实结果丢失的问题。
- 修复了多问题切换后的键盘焦点、自定义答案、多选答案和中文分片内容处理问题。
- 简化了空闲界面的状态展示，并改进了活动提示与减少动态效果设置的一致性。

## 适配范围

每种软件的 CLI、IDE、桌面端和插件均按实际接口分别记录；观察通道只显示状态，权限仍由原客户端处理。

完整覆盖范围、固定版本及剩余限制见[适配矩阵](https://github.com/Meteorkid/XIsland/blob/v2.0.0/docs/compatibility/README.md)；本次发行的构建与测试记录见[公开验证摘要](https://github.com/Meteorkid/XIsland/blob/v2.0.0/docs/compatibility/release-verification-2.0.0.json)。

最终 2.0.0 构建通过了 1,017 项 Swift 测试、122 个编译桥接场景、42 项扩展测试、6 组隔离应用回归与旧历史迁移。Claude Code 2.1.234 的真实读取、首条提示及时保存和岛上拒绝写入已在最终构建复验；使用本地模拟模型，没有发送允许决定。Kimi 的部分原生场景证据来自此前开发构建，本轮通过了隔离应用回归，未重跑其全部原生场景。以上不代表所有客户端、版本或真实服务商全部通过。

Windows 源码仍保持独立的 0.1.3 预览版版本号；本次 macOS 安装包不代表 Windows 实机验收已完成。

[GitHub 自动检查](https://github.com/Meteorkid/XIsland/actions/runs/38883244324)已通过；云端跳过的界面快照及 TypeScript 消息检查均已在本地发行测试执行。

## 安装与升级

- 安装包适用于 Apple Silicon，最低系统版本为 macOS 14。
- 升级前建议保留现有历史备份，恢复方法见[历史备份与恢复说明](https://github.com/Meteorkid/XIsland/blob/v2.0.0/docs/history-recovery.md)。
- Roo Code / PearAI 观察扩展的安装与能力限制见[扩展说明](https://github.com/Meteorkid/XIsland/blob/v2.0.0/Sources/XIslandVSCode/README.md)。

## macOS Gatekeeper

If macOS blocks the app after installing from the DMG, run:

```bash
xattr -cr /Applications/X\ Island.app
```

Alternatively: **System Settings → Privacy & Security** → scroll to the message about X Island → **Open Anyway**.
